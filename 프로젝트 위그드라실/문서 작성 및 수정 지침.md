# 문서 작성 및 수정 지침

## 목적

이 문서는 프로젝트 위그드라실 공통 설정과 각 시리즈의 설정 문서를 작성·수정·개편할 때 적용하는 공통 품질 기준이다. 시리즈별 메타데이터와 분류값은 해당 시리즈의 `AGENTS.md`와 템플릿을 따른다.

## 사전 확인

문서 작업 전에는 다음을 확인한다.

1. 프로젝트 설정 루트 `AGENTS.md`
2. 대상 시리즈 또는 공통 설정 폴더의 `AGENTS.md`
3. 대상 문서군의 템플릿
4. 동일 개념을 다루는 기존 정본 문서
5. 연결되는 신격·세력 관계·비밀 설정·스토리 설계 문서

시리즈나 하위 폴더를 추정으로 만들지 않는다. 실제 폴더 구조와 대상 경로를 확인한다.

## 내용 보존

기존 문서를 수정할 때에는 고유명사, 수치, 연대, 인과관계, 공개 수준, 확정 여부를 보존한다. 사용자가 확정한 설정을 제안이나 가능성으로 약화하지 않으며, 미확정 자료를 정설로 승격하지 않는다.

문체를 다듬는 과정에서 정보가 삭제되거나 의미가 바뀌지 않도록 수정 전후를 대조한다. 충돌이 발견되면 임의로 해결하지 않고 충돌 지점과 선택지를 분리한다.

## 세계관 내부 서술

설정 본문은 세계 안에서 성립하는 기록처럼 작성한다. 다음과 같은 제작·운영 관점 표현은 본문에서 피한다.

- 이 문서는
- 설정상
- 플레이어
- GM
- 세션
- 캠페인
- TRPG
- 이미지 생성
- 시나리오 활용
- 문서 작성 시

운영 정보가 필요하면 본문이 아니라 별도의 지침·README·주석 문서로 분리한다.

## 문단과 밀도

설정 문서의 기본 단위는 불릿이 아니라 설명형 문단이다. 각 섹션은 단순 정의를 넘어서 다음 가운데 필요한 요소를 포함한다.

- 기원과 형성 과정
- 현재의 구조와 작동 원리
- 사회·문화·생태에 미치는 영향
- 이해관계자와 갈등
- 다른 설정과의 연결
- 현재 시점의 변화와 사건 가능성

분량을 기계적으로 늘리지 않는다. 같은 정보를 반복하기보다 원인, 결과, 인식, 예외를 보강한다.

## 문체

한국어 어순과 자연스러운 호흡을 우선한다. 번역투, 명사 나열, 과도한 피동형, 동일한 접속어 반복, `단순히 A가 아니라 B다` 같은 상투적 대조를 남용하지 않는다.

짧은 문장과 긴 문장을 섞되, 한 문단 안에서 같은 내용을 여러 번 되풀이하지 않는다. 고유명사와 핵심 개념은 처음 등장할 때 충분히 설명하고 이후에는 자연스럽게 사용한다.

## 공개 수준

공개 일반 설정과 비밀 설정을 분리한다. 공개 문서에서 비밀의 결론을 직접 노출하지 않으며, 필요한 경우 흔적·소문·관찰 가능한 현상만 남긴다.

세력 관계 문서는 관계의 상태뿐 아니라 원인, 쟁점, 외부에 알려진 수준을 구분한다. 스토리 설계 문서는 확정 설정과 예정 전개를 섞지 않는다.

## 공통 설정과 시리즈 설정

`위그드라실` 공통 설정은 프로젝트 전체에 적용되는 개념과 연결 규칙을 다룬다. 시리즈 문서는 해당 시리즈에서의 구체적인 발현, 역사, 예외를 다룬다.

두 문서가 다르게 보일 때에는 먼저 적용 범위를 확인한다. 공통 규칙의 시리즈별 발현 차이는 충돌이 아닐 수 있다. 같은 범위에서 모순될 때에는 문서 상태, 최신성, 사용자의 확정 지시를 대조한다.

## 사후 점검

작업 후에는 다음을 확인한다.

- 제목과 프론트매터가 대상 시리즈 규칙에 맞는가
- 문서가 올바른 공개 수준과 폴더에 배치되는가
- 고유명사·수치·연대·인과관계가 보존되었는가
- 공통 설정과 시리즈 설정의 범위가 구분되는가
- 관련 문서 링크와 명칭이 일치하는가
- 번역투와 기계적 반복이 남아 있지 않은가
- 새로 추가한 내용이 기존 정본과 충돌하지 않는가
- 수정본이 Google Drive 직접 반영이 아닌 로컬 산출물로 제공되는가
