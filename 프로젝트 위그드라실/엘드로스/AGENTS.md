# 엘드로스 문서 작성 지침

이 폴더와 하위 폴더에서는 상위 `프로젝트 위그드라실/AGENTS.md`의 공통 운영 규칙을 따른다. 아래 내용은 엘드로스 문서 작성에 추가로 적용하는 기준이다.

## 설정 문서 작성·수정 사전 읽기

`설정` 문서를 새로 작성하거나 수정하기 전에는 반드시 프로젝트 설정 루트의 [문서 작성 및 수정 지침](../문서 작성 및 수정 지침.md)을 먼저 읽고 따른다. 해당 문서는 본문 형식·문단·표현·사후 점검의 기본 규칙이며, 이 문서는 엘드로스 고유의 메타데이터와 분류 기준을 보완한다.

## 폴더 구조

- `비밀 설정`: 아직 공개 전인 설정
- `설정`: 공개된 설정
- `신격`: 공개된 신격 정보
- `이미지`: 이미지 자료
- `템플릿`: 설정 양식
- `설정 정비`: 신규 적용 사항과 변경 예정 사항
- `스토리 설계`: 이야기 전개와 사건 설계
- `세력 관계`: 세력, 인물, 단체 사이의 관계

엘드로스는 후속 확장 대상이더라도 위 폴더 골격을 유지한다.

## 공통 메타데이터

새 문서는 YAML 프론트매터를 기본으로 사용한다.

- `uuid`: 제목·파일명·링크가 바뀌어도 유지하는 고유 식별자
- `title`: 공통 제목 키. `이름`을 사용하지 않는다.
- `docType`: 문서군 판별값
- `thumbnail`: 값이 없으면 반드시 `''`
- `status`: 문서 진행 상태
- `created_at`: 자동 생성 항목
- `updated_at`: 자동 갱신 항목

기본 `docType`은 `setting`, `deity`, `secret_setting`, `relation`, `story_design`, `maintenance`, `template`을 사용한다.

## 템플릿 문서

템플릿은 신규 문서 작성의 기준 원본이다. YAML 프론트매터에 `title`, `uuid`, `docType: template`, `thumbnail: ''`, `status`, `created_at`, `updated_at`을 포함한다. 빈 값은 `-`가 아니라 반드시 `''`로 기록한다.

현재 템플릿은 `설정_기본`, `설정_국가`, `설정_대륙`, `설정_도시`, `설정_인물`, `설정_사건`, `설정_종족`, `설정_몬스터`, `설정_아이템`, `설정_단체`, `설정_길드`, `설정_클랜`, `설정_클래스`, `신격_기본` 템플릿으로 구성한다.

## 설정 문서

`title`, `uuid`, `docType: setting`, `thumbnail: ''`, `status`, `type`, `subtype`, `region`, `created_at`, `updated_at`을 사용한다.

- `status`: `시작 전`, `임시작성`, `진행 중`, `완료`
- `type`: `종족`, `사건`, `인물`, `아이템`, `지역`, `대륙`, `국가`, `도시국가`, `단체`, `주요 개념`, `개념`, `신격`, `도시`, `지형`, `부족국가`, `클래스`
- `subtype`: 필요에 따라 `시스템`, `길드`, `클랜`, `장비`, `기기`, `역사` 등을 사용한다.
- `region`: 작품 내 권역 체계가 정리된 뒤 그 기준에 맞춰 사용한다.

분류는 다음 원칙을 따른다.

- 클래스 개별 문서는 파일명을 `클래스-문서명`으로 하고 `type: 클래스`를 사용한다. 클래스 체계 총괄 문서는 `type: 주요 개념`이다.
- 헌터, 게이트, 각성 구조처럼 세계 규칙이나 작동 원리는 `type: 개념` 또는 `type: 주요 개념`을 우선한다.
- 길드·클랜 개별 문서는 `type: 단체`와 각각 `subtype: 길드`, `subtype: 클랜`을 사용한다.
- 기술물과 장비성 사물은 `type: 아이템`을 우선하고, 필요하면 `subtype`으로 보완한다.
- 몬스터는 `type: 종족`, `subtype: 몬스터`로 기록한다.
- 도시·인물·사건 개별 문서는 각각 `type: 도시`, `type: 인물`, `type: 사건`을 사용한다.

## 공통 문서 규칙

비밀 설정, 설정 정비, 신격, 세력 관계, 스토리 설계 문서는 상위 `프로젝트 위그드라실/AGENTS.md`에 정의된 각 문서군의 YAML 필드와 선택값을 따른다.

본문은 첫 `## 개요` 뒤에 필요할 때만 실제 내용 섹션을 두고, 모든 문서에 `## 항목`을 둔다. `항목`의 본문은 공백을 제외하고 정확히 `내용`으로 고정하며, `항목`은 마지막 섹션 또는 선택 `## 요약` 바로 앞의 마지막에서 두 번째 섹션으로 둔다. 요약은 실제 요약 내용이 있을 때만 `항목` 아래에 둔다.

세력 관계의 연결 항목은 노션 URL이 아닌 옵시디언 위키 링크 `[[문서명]]`으로 기록한다. 파일명 끝의 노션 32자리 아이디는 유지하지 않으며, 내부 링크도 아이디 없는 최종 문서명을 사용한다. 원본 노션 URL은 허용하지 않고, 매핑이 애매하면 수동 검토 목록으로 분리한다.

`엘드로스 임시` 같은 구버전 보관 폴더는 정리 대상에서 제외한다.
