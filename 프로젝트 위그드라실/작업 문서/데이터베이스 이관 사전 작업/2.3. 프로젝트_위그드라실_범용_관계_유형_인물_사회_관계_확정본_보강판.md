# 프로젝트 위그드라실 범용 관계 유형 정리 — 인물 사회 관계

> 상태: 브레인스토밍 확정본  
> 범위: 대인·감정, 계약·맹세·의무, 구속·통제·범죄 관계  
> 원칙: 관계의 주체와 대상은 모두 같은 월드의 `documents`에 등록된 문서만 허용한다.

| --- | --- | --- | --- | --- |
| 인물 | 친구임 | 친구임 | 인물 | 대칭 |
| 인물 | 연인임 | 연인임 | 인물 | 대칭 |

### 설명

- `친구임`, `연인임`, `경쟁함`, `협력함`, `공모함`은 양쪽에 같은 의미가 성립하는 대칭 관계다.
- `짝사랑함`, `신뢰함`, `존경함`, `동경함`, `경계함`, `의심함`, `적대함`은 한쪽에만 성립할 수 있는 방향 관계다.
- `증오함`은 강한 부정 감정, `원한을 품음`은 과거 피해에 기반한 지속 감정, `복수하려 함`은 실제 목표와 행동 의지를 뜻한다.
- `배신함`은 기존 신뢰·충성·협력 관계를 깨뜨린 행위다.
- `결별함`은 친구·연인·협력 관계 등을 일방적으로 종료한 사실이다.

### 예시

```text
인물 A ↔ 친구임 ↔ 인물 B
인물 C → 짝사랑함 → 인물 D
인물 E → 경계함 → 인물 F
인물 G → 원한을 품음 → 인물 H
인물 I → 배신함 → 단체 J
```

## 2. 계약·맹세·의무 관계

| 대상 1 | 관계 | 역관계 | 대상 2 | 방향 |
| --- | --- | --- | --- | --- |
| 인물·단체·국가·신격 | 계약함 | 계약 상대임 | 인물·단체·국가·신격 | 대칭 |
| 인물·단체 | 맹세함 | 맹세 대상임 | 인물·단체·국가·신격 | 방향 |
| 인물·단체·국가 | 충성함 | 충성받음 | 인물·단체·국가·신격 | 방향 |
| 인물·단체·국가 | 봉신임 | 주군임 | 인물·단체·국가 | 방향 |
| 인물·단체·국가·신격 | 후원함 | 후원받음 | 인물·단체·국가 | 방향 |
| 인물·단체·국가 | 보증함 | 보증받음 | 인물·단체·국가 | 방향 |
| 인물·단체·국가 | 채무를 짐 | 채권자임 | 인물·단체·국가 | 방향 |
| 인물·단체·국가·신격 | 의무를 부과함 | 의무를 짐 | 인물·단체·국가 | 방향 |
| 인물·단체·국가 | 명령함 | 명령받음 | 인물·단체 | 방향 |
| 인물·단체·국가 | 의뢰함 | 의뢰받음 | 인물·단체 | 방향 |
| 인물·단체·국가·신격 | 금기를 부과함 | 금기를 짐 | 인물·단체·국가 | 방향 |
| 인물·단체·국가·신격 | 권리를 부여함 | 권리를 부여받음 | 인물·단체·국가 | 방향 |

### 설명

- `계약함`: 양 당사자가 조건과 의무에 합의함
- `맹세함`: 상대의 동의 없이도 성립할 수 있는 선언적 약속
- `충성함`: 지속적인 복종·헌신·정치적 귀속
- `봉신임`: 제도화된 주군·봉신 관계
- `후원함`: 자금·권력·신앙·정치적 보호를 지속적으로 지원함
- `보증함`: 신뢰성·채무·행위를 대신 책임짐
- `채무를 짐`: 돈·물품·은혜·마법적 대가를 갚아야 함
- `의무를 부과함`: 법·계약·신앙·신분에 따른 책임을 지움
- `명령함`: 위계 권한에 따른 구체적 지시
- `의뢰함`: 명령권 없이 과업을 요청하고 수락함
- `금기를 부과함`: 특정 행위를 금지함
- `권리를 부여함`: 통치권·사용권·채굴권·계승권·면책권 등을 허용함

### 예시

```text
용병단 ↔ 계약함 ↔ 왕국
성기사 → 맹세함 → 신격
기사 → 충성함 → 국왕
귀족 → 봉신임 → 군주
신격 → 권리를 부여함 → 교단
```

### 설명

- `정신을 지배함`: 판단·감정·기억·의지를 직접 장악함
- `행동을 강제함`: 의지는 남아 있지만 특정 행동을 반드시 하게 만듦
- `행동을 제약함`: 특정 행동을 하지 못하게 하거나 선택 범위를 제한함
- `체포함`: 법적·강제적으로 신병을 확보함
- `구금함`: 확보한 대상을 지속적으로 가둠
- `포로로 삼음`: 전쟁·전투의 결과로 억류함
- `인질로 삼음`: 제3자의 행동을 강제하기 위해 억류함
- `노예로 삼음`: 자유와 권리를 구조적으로 박탈함
- `감시함`, `추적함`, `수배함`: 관찰·추적·공식 지정의 차이를 가진다.
- `협박함`: 위해나 불이익을 예고해 선택을 압박함
- `세뇌함`: 신념·기억·가치관을 반복 개입으로 재구성함
- `통제함`: 대상의 행동·판단·기능을 외부에서 지속적으로 통제함
- `봉인함`: 존재·권능·이동·기능을 장기간 제한함
- `착취함`: 노동·자원·권리·생명력을 부당하게 이용함
- `약탈함`: 재산·자원·거점을 강제로 빼앗음
- `잠입함`: 허가 없이 조직·국가·장소 내부로 숨어 들어감
- `해방함`: 구속·노예·봉인·억류 상태에서 벗어나게 함

### 예시

```text
저주받은 왕관 → 정신을 지배함 → 국왕
제국 → 행동을 강제함 → 용병단
금제 장치 → 행동을 제약함 → 포로
저주받은 장치 → 통제함 → 드로이드
국가 → 수배함 → 반역자
신격 → 봉인함 → 용종
해방군 → 해방함 → 노예 집단
```

## 5. 등록 원칙

- 관계의 양 끝은 같은 월드의 등록 문서여야 한다.
- 관계 유형별 대상 1·대상 2 권장 카테고리를 기준으로 앱의 문서 목록을 필터링한다.
- 대칭 관계는 하나의 레코드만 저장한다.
- 방향 관계는 정방향 관계명과 역관계 표시명을 함께 가진다.
- 기간, 상태, 강제 방식, 원인, 조건, 대상 범위는 관계 보조 속성으로 기록한다.
- `용서함`, `화해함`은 범용 관계에서 제외한다.
- `처형함`, `암살함`, `구출함`은 사건·인과 관계 파트에서 다룬다.
