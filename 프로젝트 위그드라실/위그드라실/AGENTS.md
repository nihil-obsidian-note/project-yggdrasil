# 위그드라실 공통 설정 지침

## 역할

이 폴더는 프로젝트 위그드라실의 모든 시리즈를 포괄하는 공통 설정 허브다. 이 폴더 자체는 하나의 시리즈가 아니다.

## 저장 범위

- `설정`: 공통 우주론, 세계 간 연결, 공통 용어, 프로젝트 전체에 적용되는 원리
- `비밀 설정`: 모든 시리즈를 관통하지만 공개되지 않은 진실과 상위 비밀

시리즈 하나에만 적용되는 역사, 지역, 인물, 제도, 예외는 해당 시리즈 폴더에 둔다.

## 검색 순서

공통 개념이나 시리즈 간 연결을 묻는 요청은 이 폴더를 먼저 검색한 뒤 관련 시리즈 문서를 대조한다. 특정 시리즈에서의 발현을 묻는 요청은 해당 시리즈를 먼저 읽고 필요한 경우 이 폴더로 올라온다.

## 충돌 판정

공통 문서와 시리즈 문서가 다르게 서술되더라도 적용 범위가 다르면 충돌로 단정하지 않는다. 공통 문서는 전체 규칙을, 시리즈 문서는 지역적 발현과 예외를 설명할 수 있다.

동일한 범위에서 모순될 경우에는 사용자의 최신 확정 지시, 문서 상태, 수정 시점과 관련 문서를 대조하고 임의로 병합하지 않는다.

## 문서 작성

문서를 작성하거나 수정할 때에는 상위 `프로젝트 위그드라실/AGENTS.md`와 `문서 작성 및 수정 지침.md`를 먼저 읽는다. 공통 설정이 특정 시리즈에 미치는 영향은 관련 시리즈 문서와 연결하되, 시리즈 고유 내용을 이 폴더에 중복 복제하지 않는다.
