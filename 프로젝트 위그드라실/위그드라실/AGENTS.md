# 위그드라실 공통 설정 지침

## 역할

이 폴더는 프로젝트 위그드라실의 모든 시리즈를 포괄하는 공통 설정 허브다. 이 폴더 자체는 하나의 시리즈가 아니다.

공통 문체·밀도·AI 상투구 제거 규칙은 이 문서에 복제하지 않고 설정 루트 `문서 작성 및 수정 지침.md`와 8번 점검 수칙을 따른다. 현재 시리즈의 메타데이터, 분류, 템플릿, 고유 폴더 역할이 바뀌면 이 `AGENTS.md`와 관련 템플릿을 함께 갱신한다.

변경 사항이 다른 시리즈나 공통 설정에도 적용되어야 한다면 시리즈 규칙으로 남기지 않고 설정 루트와 8번 기능의 공통 지침으로 승격한다. 상위 라우팅에 영향을 주는 폴더명·ID·문서군 변경은 프롬프트 루트와 TRPG 데이터 루트의 진입 문서에도 반영한다.

## 저장 범위

- `설정`: 공통 우주론, 세계 간 연결, 공통 용어, 프로젝트 전체에 적용되는 원리
- `비밀 설정`: 모든 시리즈를 관통하지만 공개되지 않은 진실과 상위 비밀

시리즈 하나에만 적용되는 역사, 지역, 인물, 제도, 예외는 해당 시리즈 폴더에 둔다.

## 검색 순서

공통 개념이나 시리즈 간 연결을 묻는 요청은 이 폴더를 먼저 검색한 뒤 관련 시리즈 문서를 대조한다. 특정 시리즈에서의 발현을 묻는 요청은 해당 시리즈를 먼저 읽고 필요한 경우 이 폴더로 올라온다. 시리즈에 `인덱스` 폴더가 있으면, 여러 정본 문서의 분류와 연결을 빠르게 파악하는 보조 탐색 경로로 함께 확인하되, 공통 사실과 개별 사실의 최종 근거는 각각의 정본 문서에서 확인한다.

## 충돌 판정

공통 문서와 시리즈 문서가 다르게 서술되더라도 적용 범위가 다르면 충돌로 단정하지 않는다. 공통 문서는 전체 규칙을, 시리즈 문서는 지역적 발현과 예외를 설명할 수 있다.

동일한 범위에서 모순될 경우에는 사용자의 최신 확정 지시, 문서 상태, 수정 시점과 관련 문서를 대조하고 임의로 병합하지 않는다.

## 문서 작성

문서를 작성하거나 수정할 때에는 상위 `프로젝트 위그드라실/AGENTS.md`와 `문서 작성 및 수정 지침.md`를 먼저 읽는다. 공통 설정이 특정 시리즈에 미치는 영향은 관련 시리즈 문서와 연결하되, 시리즈 고유 내용을 이 폴더에 중복 복제하지 않는다.
