## 설정 검색 원칙

- 사용자가 시리즈명을 지정하면 해당 직계 하위 폴더를 우선한다.
- 사용자가 `설정 폴더에서 찾아라`라고만 하면 이 루트 전체를 검색한다.
- 공통 우주론, 세계 간 연결, 공통 용어, 프로젝트 전체 규칙은 `위그드라실` 폴더를 먼저 확인한다.
- 시리즈 고유 사실은 해당 시리즈 폴더가 정본이다.
- 시리즈에 `인덱스` 폴더가 있으면, 대륙·세력·정치 체제처럼 여러 정본 문서를 가로질러 찾는 작업에서 먼저 확인한다. 인덱스는 탐색과 비교의 기준이며, 개별 사실의 최종 근거는 연결된 정본 문서다.
- 시리즈에 `라이브러리` 폴더가 있으면, 반복 적용할 분류 체계·제작 규칙·조립 기준을 확인할 때 사용한다. 라이브러리는 개별 설정을 확정하는 정본이 아니며, 관련 정본과 세력 관계 문서를 확인한 뒤 적용한다.
- 라이브러리와 개별 정본이 충돌하면 개별 정본을 우선하고, 실제 적용 결과에 맞추어 라이브러리를 후속 갱신한다.
- `위그드라실` 공통 설정과 시리즈 문서의 적용 범위가 다르면 각각의 범위를 유지한다.
- 같은 범위에서 충돌하면 임의로 합치지 않고 충돌 문서와 차이를 보고한다.

## 폴더 역할

- `설정`: 공개 일반 설정
- `신격`: 공개 신격·신앙·교단
- `비밀 설정`: 미공개 진실과 GM 전용 정보
- `세력 관계`: 세력·인물·단체 사이 관계와 공개 수준
- `스토리 설계`: 장기 플롯, 사건 설계, 공개 순서
- `설정 정비`: 문제 발견, 검토 결과, 변경 계획, 정본 적용, 검증 결과, 미해결 사항과 완료 이력을 관리하는 작업 문서군. 확정 사실은 해당 정본 문서에 반영하며, 정비 문서는 정본을 대신하지 않는다.
- `인덱스`: 여러 정본 문서를 횡단해 비교·탐색하기 위한 정리 문서
- `라이브러리`: 여러 정본에서 추출한 재사용 가능한 분류 체계·제작 규칙·조립 기준
- `데이터 창고`: 아이템·인물·특성·능력·클래스처럼 제작 기능이 만든 완성 데이터의 로컬 정본 저장소. 하위 `아이템`, `인물`, `특성`, `능력`, `클래스` 폴더를 사용하며, 시리즈 소속은 문서의 `series` 메타데이터로 판정한다.
- `템플릿`: 문서 형식과 메타데이터 기준
- `이미지`: 시각 자료
- 시리즈 고유 추가 폴더: 해당 시리즈 `AGENTS.md`의 정의를 따른다.

모든 시리즈가 동일한 하위 폴더를 가질 필요는 없다. 존재하지 않는 폴더를 임의로 가정하지 말고 실제 구조를 조회한다.

## 미세단위 제작 데이터

프롬프트 루트의 `공통/미세단위 제작 기능 등록 및 연동 지침.md`에 등록된 기능은 `미세단위 제작 기능`이다. 각 기능은 독립 실행하며, 완성 데이터는 시리즈별 `설정/` 폴더가 아니라 `데이터 창고/<유형>/`에 둔다. 룩스테라나 엘드로스 전용 데이터도 같은 경로에 저장하고 `series`에 소속 시리즈를 기록한다. 새 제작 기능이 등록되면 데이터 창고의 해당 유형 폴더와 이 루트의 데이터 창고 규칙을 함께 점검한다.

데이터 창고 문서는 기존 설정 문서의 `title`, `uuid`, `docType`, `thumbnail`, `status`, `type`, `subtype`, `region`, `created_at`, `updated_at` 메타데이터를 유지하며, 중앙 저장소에서만 `series`를 추가한다. 기존 시리즈별 설정 문서는 이 규칙만으로 자동 이동하지 않는다.

## 문서 작성·수정 사전 읽기

문서를 작성하거나 수정하기 전에는 다음 순서로 읽는다.

1. 이 `AGENTS.md`
2. `문서 작성 및 수정 지침.md`
3. `템플릿 구조 점검 수칙.md`
4. 대상 시리즈 또는 `위그드라실` 폴더의 `AGENTS.md`
5. 대상 문서군의 템플릿
6. 관련 인덱스
7. 관련 정본 문서와 세력 관계 문서
8. 작업에 적용할 관련 라이브러리

대륙 정본을 신규 작성·개편·수정하거나, 그 대륙에 속한 지형·수계·권역·국가·정치 영역·정착지·항구·거점·이동경로의 공간상 위치 또는 연결 관계를 변경할 때에는 위 순서에 앞서 `대륙 공간 배치 기준 작성 지침.md`, 대상 시리즈의 공간 배치 기준 템플릿과 해당 대륙의 공간 배치 기준을 읽는다. 한 요소가 바뀌면 다섯 레이어 전체를 교차 검증하고, 근거 없는 좌표 제안은 설정 정비에 분리한다.

인덱스와 라이브러리가 존재하지 않으면 해당 단계를 생략한다. 라이브러리를 먼저 읽었다는 이유로 개별 정본에 없는 설정을 자동 생성하거나 확정해서는 안 된다.

대상 시리즈에 `설정 정비/설정 정비 현황.md`가 있으면, 점검·정비·보강·재작성 전에 이를 읽고 같은 대상·고유명사·문제 유형의 미완료 작업이 있는지 확인한다. 기존 작업이 있으면 새 문서를 만들지 않고 그 작업에 적용 내역과 검증 결과를 갱신한다. 완료된 작업은 완료일 이후 정본 변경 여부를 확인한 뒤 재개 또는 후속 정비 생성을 결정한다.

`문서 작성 및 수정 지침.md`는 설정 저장소 안에서 독립적으로 실행할 수 있는 완결된 작업 기준이다. Codex가 이 설정 폴더를 작업 공간으로 직접 열었을 때에도 다른 프롬프트 문서를 전제로 하지 않고 이 파일을 필수 지침으로 읽는다.

설정 문서의 조회·점검·윤문·보강·개편·재작성·병합·분리·신규 작성·링크 갱신·사후 검증은 모두 `문서 작성 및 수정 지침.md`의 실행 절차와 완료 판정을 따른다. 대상 시리즈의 `AGENTS.md`와 템플릿은 시리즈별 메타데이터와 문서 구조를 보완한다.

템플릿이 존재하는 문서를 작성·수정·개편·병합·분리하거나 구조 일치 여부를 점검할 때에는 `템플릿 구조 점검 수칙.md`에 따라 적용 템플릿을 먼저 판정한다. 필수 상위 섹션은 템플릿의 이름과 순서를 따르되, 문서 고유 하위 섹션은 올바른 상위 범주 아래에서 허용한다.

## 라이브러리 운영 원칙

라이브러리는 개별 설정을 대신하는 정본이 아니라, 여러 정본에 반복 적용할 수 있도록 이미 확정된 구조를 일반화한 보조 문서군이다.

- 라이브러리는 사용자의 명시적 확정이나 실제 정본 적용 사례를 근거로 작성한다.
- 실제 적용 사례가 없는 후보 규칙은 확정 규칙과 구분한다.
- 라이브러리의 분류명·정의·조립 규칙이 변경되면 이를 사용하는 정본·인덱스·관계 문서를 함께 점검한다.
- 정본 수정으로 기존 라이브러리 정의가 맞지 않게 되면 정본을 되돌리지 않고 라이브러리를 갱신한다.
- 특정 시리즈에만 적용되는 라이브러리는 해당 시리즈 폴더에 두고, 프로젝트 전체에 공통 적용되는 라이브러리만 `위그드라실` 공통 설정 범위에 둔다.
- 라이브러리의 구체적인 적용 순서와 필수 항목은 대상 시리즈의 `AGENTS.md`를 따른다.

## 시리즈 추가 규칙

새 직계 하위 폴더가 추가되면 다음을 확인한다.

- `위그드라실`이 아닌가
- 독립된 시리즈 또는 설정 축인가
- 시리즈 루트에 `AGENTS.md`가 있는가
- 공개 설정과 비밀 설정의 저장 위치가 정의되어 있는가
- 문서 메타데이터와 템플릿 기준이 정의되어 있는가
- 인덱스 또는 라이브러리를 사용할 경우 해당 폴더의 역할과 정본 우선순위가 정의되어 있는가

위 조건이 불완전하더라도 검색 대상에서는 제외하지 않는다. 대신 구조 미정 상태로 표시하고 문서 생성 위치를 임의로 확정하지 않는다.

## 원천과 충돌 처리

우선순위는 다음과 같다.

1. 사용자의 최신 명시 지시
2. 이 설정 루트의 공통 운영 지침
3. `위그드라실` 공통 설정
4. 대상 시리즈의 정본 문서
5. 대상 시리즈의 `설정 정비`
6. 대상 시리즈의 인덱스와 라이브러리

3번과 4번은 단순 상하 관계가 아니다. 공통 설정은 프로젝트 전체 범위, 시리즈 설정은 해당 시리즈 범위를 담당한다. 동일 범위에서 실제 충돌할 때만 우선순위와 최신성을 판정한다.

인덱스와 라이브러리는 탐색·비교·재사용을 위한 보조 자료다. 개별 정본과 충돌할 경우 정본을 우선하며, 보조 자료를 정본에 맞추어 갱신한다.

설정 정본은 이 루트와 직계 하위 폴더에서만 판정한다. 루트에서 확인되지 않은 자료는 설정 근거로 사용하지 않는다.

## 파일 작업 원칙

Google Drive에 파일을 직접 생성·덮어쓰기·삭제하지 않는다. 수정본은 실제 적용 경로가 드러나는 로컬 ZIP으로 제공한다.

```text
프로젝트 위그드라실/<시리즈명>/<하위 폴더>/파일.md
프로젝트 위그드라실/위그드라실/<설정 또는 비밀 설정>/파일.md
```
