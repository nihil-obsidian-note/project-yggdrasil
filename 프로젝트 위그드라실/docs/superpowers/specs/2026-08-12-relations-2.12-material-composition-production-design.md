# 2.12 재료·구성·생산 관계 확정 설계

## 목표

2.12를 구조 사실, 자원 획득, 생물 생산, 물질 공정, 생산·순환의 독립 관계군으로 확정하고 역할별 카테고리 검증을 관계 설계와 동시에 완료한다.

## 설계 결정

- 신규 COMMON 관계는 55개이며 전역 ID 787~841을 사용한다.
- 관계 대상은 2~4개이며 숫자 슬롯 대신 의미 역할을 사용한다.
- `합금 성분임`과 `복합재 구성 재료임`은 상위 구조 관계에 통합한다.
- `변환함(물질)`을 추가하고 추상 변환과 분리한다.
- COMMON 카테고리 매핑과 룩스테라 용종 확장 매핑을 분리한다.
- 엘드로스 클래스는 2.12에서 직접 확장하지 않는다.

## 산출물

확정본, COMMON 매핑, 용종 확장 갱신, 적용 규칙, 추적, 정비, 인계, 현황, Superpowers 계획·검증·레지스트리를 하나의 배포 세트로 관리한다.
