# 20번 인물 제작 프롬프트 설계 명세

## 목적

20번 `인물 제작 프롬프트`는 소설·설정용 인물 시트를 작성·보강·점검하는 기능이다. 인물을 단순 프로필이 아니라 욕망, 결핍, 신념, 관계, 선택, 변화가 연결된 서사 주체로 설계한다.

이 기능은 주연·조연·주변인물·단역의 작성 밀도를 구분한다. 선역, 악역, 대립자, 협력자 등은 역할 등급이 아니라 태그와 서사적 기능으로 기록한다. 엑스트라는 개별 시트 작성 대상에서 제외한다.

## 역할과 양식 선택

| 역할 | 양식 | 기준 |
| --- | --- | --- |
| 주연 | 상세 인물 시트 | 욕망과 변화가 작품의 중심 축을 이끈다. |
| 조연 | 상세 인물 시트 | 독립된 욕망과 선택으로 핵심 갈등이나 주연의 변화를 바꾼다. |
| 주변인물 | 간략 인물 시트 | 반복 등장하며 관계·정보·생활권을 형성하지만 독립 변화축은 필수가 아니다. |
| 단역 | 간략 인물 시트 | 특정 장면이나 사건에서 선택·정보·충돌·전환을 담당한다. |
| 엑스트라 | 시트 없음 | 배경 밀도와 현장감을 위한 존재이며 개별 데이터로 관리하지 않는다. |

## 상세 인물 시트

상세 인물 시트는 아래 열한 구획을 사용한다.

1. 기본 정보: 이명, 역할, 성별, 성적 지향, 성적 기호, 나이, 종족, 국가
2. 한 줄 정의와 서사적 기능: 결핍-욕망-대표 선택을 잇는 한 줄 정의, 서사적 기능, 주요 대립 또는 협력 구도
3. 외형과 현재 처지: 신체·건강·제약·기억점, 소속·직위·출신·현재 위치에 이른 이유
4. 욕망과 결핍: 핵심 욕망, 단기 목표, 핵심 결핍, 두려움, 절대 금기, 숨기는 사실, 방해물, 예상 대가
5. 성격과 신념: 강점·약점, 대표 정서, 호불호, 자기·타인 인식, 가치관, 왜곡된 신념 또는 자기기만, 판단 규칙, 도덕적 경계
6. 대화와 행동: 기본·상황별 화법, 말버릇과 습관, 감정 표현, 대표 대사
7. 관계: 인물별 중첩 목록으로 겉으로 드러난 관계, 실제 감정·이해관계, 갈등 또는 기대를 기록
8. 역량과 제약: 행동·전투 양식, 강점·약점, 능력의 대가·한계, 트레잇과 어빌리티 참조
9. 과거와 갈등: 현재를 만든 사건·관계, 잔존 영향, 갈등 트리거, 감정 누적 신호, 폭발 또는 회피 방식
10. 서사 변화: 시작점, 변화를 강제할 사건, 도착점, 끝내 바꾸지 못하는 것
11. 기타: 앞선 구획에 맞지 않는 보충 정보

성적 지향과 성적 기호는 범용 시트의 기본 정보로 유지한다. 다만 해당하지 않거나 아직 정하지 않은 경우 `미정` 또는 `설정 없음`으로 기록할 수 있으며, 성격·도덕성·서사적 역할을 판정하는 기준으로 사용하지 않는다.

## 간략 인물 시트

간략 인물 시트는 아래 여섯 구획을 사용한다.

1. 역할과 개요: 역할 유형, 한 줄 정의, 서사적 기능, 등장 장면 또는 활동 범위
2. 현재 처지와 기억점: 소속·생업, 현재 처지, 신체·외형 특징, 기억 포인트
3. 성격과 표현: 강점·약점, 대표 정서, 호불호, 기본 어조, 말버릇 또는 대표 대사
4. 욕망과 행동: 핵심 욕망, 핵심 결핍 또는 제약, 절대 금기, 판단 규칙, 장면에서 취할 행동
5. 관계와 활용: 필요한 인물만 중첩 목록으로 관계·기대·갈등을 기록하고 퇴장 또는 재활용 계획을 적는다.
6. 트레잇 및 어빌리티: 필요한 경우에만 최소 정보로 기록한다.

## 서식 원칙

- 두 양식은 Markdown 제목, 일반 목록, 중첩 목록만 사용한다. 직접 작성하는 인물 시트에 표를 사용하지 않는다.
- 인물 시트의 프론트매터는 룩스테라와 엘드로스의 기존 설정 문서 규격을 따른다. `title`, `uuid`, `docType`, `thumbnail`, `status`, `type`, `subtype`, `region`, `created_at`, `updated_at`을 같은 이름과 의미로 사용한다.
- 데이터 창고 문서는 시리즈 루트 밖의 공용 저장소에 있으므로, 기존 필드 뒤에 `series`를 추가한다. `series`에는 `룩스테라`, `엘드로스`처럼 해당 데이터가 속한 시리즈를 기록한다.
- 인물 문서의 `type`은 `인물`이고, `subtype`은 `주연`, `조연`, `주변인물`, `단역` 중 하나다.
- `대립자`, `악역`, `선역`, `협력자`, `관찰자` 등은 `태그` 또는 `서사적 기능`으로 표현한다.
- 숨기는 사실은 별도의 비공개 등급이 아니라 욕망·두려움·선택의 대가와 연결되는 일반 정보로 기록한다.
- 매슬로 욕구 단계는 필수 시트 항목으로 강제하지 않는다. 필요할 때만 조합용 분석 자료에서 활용한다.
- 트라우마는 필수 전제가 아니다. 상세 시트에서는 현재를 만든 사건 또는 관계로 넓게 다룬다.
- 능력·트레잇·클래스는 인물 시트에 필요한 요약과 참조만 남긴다. 완전한 데이터는 각 소유 기능에서 관리한다.

## 조합용 레퍼런스

20번 폴더의 `라이브러리`에는 아래 다섯 범주의 조합용 참고 자료를 둔다.

1. 욕망과 결핍
2. 신념과 자기기만
3. 관계와 갈등
4. 서사적 기능과 변화
5. 화법, 행동, 기억점

레퍼런스는 고정된 성격 유형이나 정답 목록이 아니라 조합을 돕는 선택지와 점검 질문을 제공한다. 사용자의 설정이나 정본보다 우선하지 않는다.

## 데이터 창고

로컬에서 제작 기능이 만든 완성 데이터는 시리즈별 `설정/` 폴더가 아니라 프로젝트 설정 루트의 `데이터 창고`에 저장한다.

```text
프로젝트 위그드라실/데이터 창고/
├─ 아이템/
├─ 인물/
├─ 특성/
├─ 능력/
└─ 클래스/
```

룩스테라 전용 인물도 `데이터 창고/인물/`에 저장하고 `series: '룩스테라'`로 소속을 판별한다. 이후 인물·아이템·특성·능력·클래스 제작 기능은 같은 저장 원칙을 사용한다.

기존 시리즈별 `설정/인물/` 및 `설정/아이템/` 등의 문서는 이번 작업에서 이동하지 않는다. 이관은 링크·인덱스·정본 경로를 별도로 점검하는 후속 작업이다.

## 기존 기능과의 경계

- 8번은 프로젝트 위그드라실의 인물·세력·국가·사건 등 정본 설정의 확인과 수정에 사용한다.
- 12번은 종족의 생리·문화·형태를 담당한다.
- 16번은 재사용 가능한 특성을 담당한다.
- 17번은 독립된 능력의 원천·작동·효과·대가를 담당한다.
- 18번은 클래스·직업·전직 구조를 담당한다.
- 20번은 위 자료를 참조하여 특정 인물의 서사적 구조를 설계한다. 세계관 사실, 종족 구조, 능력 규칙, 클래스 구조를 중복 정의하지 않는다.

## 미세단위 제작 기능

11번 아이템 제작, 16번 특성 제작, 17번 능력 제작, 18번 클래스 제작, 20번 인물 제작은 `미세단위 제작 기능`으로 묶는다. 이 분류는 세계관 전체의 제도·역사·사건을 작성하는 8번 설정 기능과 구분하기 위한 라우팅 단위다.

- 아이템: 개별 물품·장비·유물의 구조와 활용을 제작한다.
- 특성: 대상에게 부착하거나 재사용할 짧은 성질·효과·로어 단위를 제작한다.
- 능력: 독립된 이름과 작동 구조를 가진 능력·기술·주문을 제작한다.
- 클래스: 인물 또는 집단의 직업·수행 구조·성장 방향을 제작한다.
- 인물: 욕망·결핍·신념·관계·선택·변화가 연결된 캐릭터 시트를 제작한다.

미세단위 제작 기능은 서로의 완성 데이터를 중복 정의하지 않고 참조한다. 세계관의 기존 사실 확인과 정본 수정이 필요한 경우에는 8번을 먼저 사용한다.

## 20번 기능의 파일 구조

```text
20. 인물 제작 프롬프트/
├─ AGENTS.md
├─ README.md
├─ 0. 인물 제작 마스터 프롬프트.md
├─ 1. 인물 제작 지침서.md
├─ 2. 인물 시트 점검 수칙.md
├─ 라이브러리/
│  ├─ 욕망과 결핍 레퍼런스.md
│  ├─ 신념과 자기기만 레퍼런스.md
│  ├─ 관계와 갈등 레퍼런스.md
│  ├─ 서사적 기능과 변화 레퍼런스.md
│  └─ 화법과 행동 레퍼런스.md
└─ 템플릿/
   ├─ 설정_상세 인물 시트 템플릿.md
   └─ 설정_간략 인물 시트 템플릿.md
```

## 처리 흐름

1. 요청이 인물 시트 설계·보강·점검인지, 정본 설정 변경인지, 종족·능력·클래스 설계인지 구분한다.
2. 요청 인물의 역할을 판정해 상세 또는 간략 양식을 고른다.
3. 기존 설정과 관련 인물·세력·종족·능력·클래스 자료를 필요한 범위에서 확인한다.
4. 욕망, 결핍, 신념, 관계, 선택, 변화가 서로 모순되지 않도록 시트를 작성하거나 보강한다.
5. 점검 수칙으로 역할 밀도, 관계 연결, 욕망-행동 정합성, 기존 정본과의 충돌을 확인한다.
6. 정본 변경이 필요하면 8번 절차로 넘긴다.
