# 범용 관계 유형 v1 동결 설계

## 목적

COMMON 관계 유형 936개와 대상 역할 2,813개의 DB 시드 전 기준을 고정한다.

## 설계 결정

1. 의미 영역이 다른 동명 관계 8쌍은 병합하지 않고 기존 전역 ID를 유지한 괄호형 독립 관계명으로 등록한다.
2. 같은 관계 안에서 중복된 역할명 8건은 수령자와 이전 내용이 구분되도록 정정한다.
3. 역할별 카테고리 허용은 월드별 `worldRelationshipRoleCategories`에 저장하고, COMMON·SERIES 원천 범위는 각 월드 적재 시 실제 `categoryId`로 해소한다.
4. 프로젝트·월드·카테고리 시드를 관계 데이터보다 먼저 생성한다.

## 검증 기준

- 관계 ID 1~936의 누락·중복은 0건이다.
- 관계 유형 수는 936개, 대상 역할 수는 2,813개다.
- 같은 `relationshipTypeId` 안에 중복 역할명이 없다.
- 세부 목록·해시·정정 행은 `설정 정비/데이터베이스 이관 사전 작업/검토 및 추적/범용 관계 유형 v1 최종 검토 및 동결.md`를 따른다.
