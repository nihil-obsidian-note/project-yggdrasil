# 2.13 개념·법칙·영향 관계 확정 설계

## 목표

2.13을 정의·규범·영향·추상 상태 변화·생태 영향·의존·상성 관계군으로 확정하고 COMMON과 SERIES 역할 매핑을 동시에 완료한다.

## 설계 결정

- 후보 47개를 신규 45개, 기존 재사용 1개, 통합 제외 1개로 확정한다.
- 신규 전역 ID는 842~886을 사용한다.
- `작용함`은 일반 영향에 통합하고 `결합함`은 ID 836을 재사용한다.
- 괄호형 독립 관계 14개를 별도 relation type으로 등록한다.
- COMMON과 룩스테라 용종·엘드로스 클래스 SERIES 매핑을 분리한다.
- 2.13 이관 대기와 보류를 모두 해소한다.

## 산출물

확정본, COMMON 매핑, 용종·클래스 확장, 적용 규칙, 추적, 정비, 인계, 현황, Superpowers 계획·검증·설정 레지스트리를 하나의 세트로 관리한다.
