## 구조 검증

- 범용 매핑에는 범용 11개 카테고리만 유지했다.
- 용종과 클래스 확장은 각각 별도 파일로 분리했다.
- DB 매핑 범위는 `COMMON`과 `SERIES`로 구분했다.
- UI 허용 카테고리는 범용 매핑과 현재 시리즈 확장 매핑의 합집합으로 계산한다.
- 다른 시리즈의 확장 카테고리는 노출하거나 저장하지 않는다.
- 기존 운영 문서 6종에서 과거 `전체 13개`, `13개 메인 카테고리` 표현은 검출되지 않았다.

## 최종 판정

범용 11개 관계 대상 카테고리 매핑과 분리된 세계별 확장 매핑 구조가 일치한다. 용종·클래스 확장 정본과 DB·UI 적용 규칙은 검증을 통과했다.

현재 남은 클래스 관련 미결은 엘드로스 전용 relation type 후보 `클래스를 가짐 ↔ 보유 클래스임`, `사용 가능함 ↔ 사용 가능 클래스임`의 정식 채택 여부다. 다음 범용 관계 작업은 2.11 실제 범위 재구성이다.
