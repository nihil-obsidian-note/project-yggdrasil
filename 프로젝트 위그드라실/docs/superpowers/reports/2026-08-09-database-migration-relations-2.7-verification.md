# 데이터베이스 이관 범용 관계 유형 2.7 완료 검증

## 작업 범위

프로젝트 위그드라실의 데이터베이스 이관 사전 작업 중 `2.7 전투·갈등·승패 관계`를 검토·확정한 결과를 기록한다. 전체 데이터베이스 이관 사전 작업은 아직 진행 중이며, 이 보고서는 2.7 세부 단계 완료 검증이다.

## 검증 대상

- `2.7. 범용 관계 유형 - 전투·갈등·승패 관계 확정본.md`
- `범용 관계 유형 검토 지침.md`
- 2.1~2.6 기존 범용 관계 확정본
- `2.5.1 괄호형 관계 분리 확정 갱신본.md`
- `범용 관계 유형 검토·이관 추적 문서.md`
- `데이터베이스 이관 사전 작업 정비.md`

## 검증 결과

- 2.7-1~2.7-8 전 범위를 검토했다.
- 상황·조건·원인·결과가 달라 사용자 선택 가치가 있는 괄호형 관계는 별도 relation type으로 유지했다.
- `항복을 거부함(결사항전)`은 `결사항전함`과 의미가 겹치므로 통합했다.
- `점유함`과 `점령함`, `이탈함`과 `철수함`, `저지함`과 `차단함`, `격파함`·`제압함`·`무력화함`, `생포함`·`포획함`·`포로로 삼음`은 의미 차이를 확인하여 병존시켰다.
- 2.5·2.6에서 이관 대기였던 `침공함`, `항복함`, `굴복함`, `승전함`, `패전함`, `도발함`, `전복을 시도함`을 모두 회수했다.
- `침탈함 계열`은 독립 기본 관계로 남기지 않고 침공·침입·점령·약탈·점유·영유 계열로 분해했다.
- 전투·작전 중심 `투입함`은 기존 2.6 `투입함`을 재사용한다.

## 상태 판정

- 2.7 단계: **완료**
- 데이터베이스 이관 사전 작업 전체: **진행 중**

## 후속 작업

1. Superpowers 작업 레지스트리에 2.7 완료 이력을 반영한다.
2. `범용 관계 유형 검토·이관 추적 문서.md`를 2.7 확정 상태로 갱신한다.
3. `데이터베이스 이관 사전 작업 정비.md`와 관련 인계·현황 문서의 누적 관계 수와 다음 작업을 갱신한다.
4. 이후 2.8 지식·연구·발견 관계 검토를 시작한다.
