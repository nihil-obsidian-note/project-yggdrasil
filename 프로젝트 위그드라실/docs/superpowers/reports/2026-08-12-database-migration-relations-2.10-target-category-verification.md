## 범용·세계별 카테고리 구조 교정

- 범용 카테고리: 개념·신격·국가·도시·단체·종족·인물·아이템·사건·설화·지형의 11개
- 룩스테라 확장 카테고리: 용종
- 엘드로스 확장 카테고리: 클래스
- 모든 범용 관계의 기본 대상 카테고리 매핑에서는 용종과 클래스를 제외했다.
- `종족·용종`에서 용종을 제거하면서 단일 카테고리 역할은 65개 증가하고 복수 제한 역할은 65개 감소했다.
- 세계별 확장 카테고리는 범용 전체 허용에 자동 포함하지 않으며 별도 확장 매핑으로 관리한다.

## Drive 검증

신규 확정본, 대상 카테고리 매핑, 실행 계획을 지정 폴더에 업로드하고 파일명과 부모 폴더를 확인했다.

기존 운영 문서 4개는 기존 Drive 파일 ID를 유지한 채 갱신했다. 재조회에서 누적 753개, 대상 역할 2,141개, 다음 작업 2.11 전환이 모두 확인됐다.

- 2.10 확정본: 관계 행 48개
- 대상 카테고리 매핑: 관계 행 753개, 빈 카테고리 0개
- 추적 문서: 번호가 중복되지 않은 13개 상위 절
- 정비·인계·현황: 2.10 확정과 대상 카테고리 정본 경로 반영
