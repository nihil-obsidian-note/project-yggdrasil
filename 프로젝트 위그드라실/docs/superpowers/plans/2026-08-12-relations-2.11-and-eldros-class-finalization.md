# 2.11 및 엘드로스 클래스 관계 확정 세트 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use `superpowers:executing-plans` to execute this tightly coupled documentation plan. Use `superpowers:verification-before-completion` before completion claims.

**Goal:** 2.11 범용 관계 34개와 엘드로스 클래스 전용 관계 7개를 확정하고, 재분류·매핑·적용 규칙·정비·추적·검증 문서를 하나의 확정 세트로 동기화한다.

**Architecture:** `COMMON` 관계는 2.1~2.11 확정본과 범용 매핑으로 관리하고, 엘드로스 클래스 전용 관계는 `SERIES` 정본으로 분리한다. `파문함 ↔ 파문당함`은 2.2에서 삭제하여 2.11-4로 재분류하되 기존 전역 번호는 재사용하지 않는다. 모든 집계는 활성 관계 수와 대상 역할 슬롯 수를 기준으로 다시 계산한다.

**Tech Stack:** Markdown, ripgrep, shell 검증, ZIP, Google Drive Superpowers 문서 운영

## Global Constraints

- 2.11 구성 관계는 34개이며 실제 신규 `COMMON` relation type은 33개다.
- `파문함 ↔ 파문당함`은 기존 2.2에서 2.11-4로 재분류한다.
- 2.1~2.10 활성 관계는 752개, 대상 역할은 2,139개로 정정한다.
- 2.1~2.11 누적 `COMMON` 관계는 786개다.
- 엘드로스 클래스 관계 7개는 `SERIES` 범위로 별도 관리한다.
- 관계 대상은 최소 2개, 최대 4개다.
- 기존 정본 파일명은 변경하지 않는다.
- 프로젝트 정본 세트는 원래 폴더 구조를 보존한 ZIP으로 제공한다.
- Superpowers 계획·검증 문서는 ZIP에 넣지 않고 Drive 지정 폴더에 직접 저장한다.
