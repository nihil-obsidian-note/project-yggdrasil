# 2.8 지식·연구·발견 관계 기록 정합화 Implementation Plan

**Goal:** 이미 존재하는 2.8 최종 확정본과 설정 정비·Superpowers 기록의 누락을 교정한다.

**Scope:** 과거 2.8 검토 과정을 재구성하거나 실행일을 추정하지 않는다. 현재 확정본의 존재, 관계 수, 현재 다음 작업을 근거로 기록 위치와 상태를 정합화한다.

## 확인 기준

- 정본: `설정 정비/데이터베이스 이관 사전 작업/범용 관계 유형/2.8. 범용 관계 유형 - 지식·연구·발견 관계 확정본.md`
- 정본 상태: `최종 확정본`
- 관계 수: 37개
- 현재 후속 범위: 2.13 개념·법칙·영향 관계

## 처리 순서

1. 2.8 확정본의 상태·범위·관계 수를 다시 확인한다.
2. 대표 정비 문서에서 2.8을 다음 작업으로 남긴 과거 상태를 역사 기록으로 보존하고, 현재 상태를 2.12 확정·2.13 검토 대기로 갱신한다.
3. 중앙 설정 정비 현황의 누적 수치와 다음 작업을 현재 기준으로 갱신한다.
4. 사후 정리의 검증 보고서를 생성하고 설정 전용 레지스트리에 완료 이력으로 등록한다.
