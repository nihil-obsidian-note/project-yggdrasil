# 대륙 공간 배치 관리 기능 구현 계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use `superpowers:executing-plans` to execute this plan inline. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 대륙 설정의 공간상 사실이 생성·수정될 때마다 다섯 공간 배치 레이어를 필수로 대조하도록 8번 설정 관련 요청 기능과 설정 정본 지침을 연결한다.

**Architecture:** 상세 표기와 검증 규칙은 설정 루트의 공통 지침에만 둔다. 8번 기능은 대륙 공간 배치 요청을 라우팅하고, 대상 시리즈의 정본·인덱스·설정 정비를 읽도록 하는 별도 운용 수칙으로 이를 호출한다. 상위 프롬프트는 호출 조건만 유지한다.

**Tech Stack:** Markdown, YAML frontmatter, Obsidian 위키 링크

## Global Constraints

- 설정 정본은 개별 설정 문서이며 공간 배치 기준은 인덱스형 내부 참조 자료다.
- 대륙 정본 또는 공간상 사실이 바뀌면 다섯 레이어 전체를 교차 검증한다.
- 근거 없는 좌표·경로는 정본으로 승격하지 않고 설정 정비로 분리한다.
- Google Drive 원격 조작 없이 로컬 파일만 수정한다.
- 커밋과 푸시는 수행하지 않는다.
