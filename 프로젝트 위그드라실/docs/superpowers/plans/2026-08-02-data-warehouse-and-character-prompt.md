# 데이터 창고와 20번 인물 제작 프롬프트 구현 계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 제작 기능의 완성 데이터를 설정 루트 `데이터 창고`에 일관되게 저장하고, 이를 사용하는 20번 인물 제작 프롬프트를 구축한다.

**Architecture:** 제작 프롬프트는 작성 절차·라이브러리·템플릿을 제공하고, 완성 데이터의 정본 경로는 프로젝트 설정 루트의 `데이터 창고/<유형>/`으로 통일한다. 데이터 창고 문서는 기존 시리즈 설정 문서 메타데이터를 유지하되, 중앙 저장소에서 시리즈 소속을 구분하기 위해 `series`만 추가한다.

**Tech Stack:** 로컬 Markdown, YAML 프론트매터, PowerShell 검증, 프로젝트 위그드라실 및 TRPG 프롬프트 지침

## Global Constraints

- 데이터 창고 위치는 `프로젝트 위그드라실/데이터 창고/`다.
- 하위 유형은 `아이템`, `인물`, `특성`, `능력`, `클래스`다.
- 룩스테라 전용 데이터도 데이터 창고에 저장하고 `series: '룩스테라'`로 소속을 기록한다.
- 기존 설정 메타데이터 `title`, `uuid`, `docType`, `thumbnail`, `status`, `type`, `subtype`, `region`, `created_at`, `updated_at`의 이름과 의미를 유지한다.
- 데이터 창고 문서에만 `series`를 추가한다.
- 인물 시트에는 표를 사용하지 않는다. Markdown 제목·일반 목록·중첩 목록만 사용한다.
- 주연·조연은 상세 시트, 주변인물·단역은 간략 시트를 쓴다. 엑스트라는 개별 시트를 만들지 않는다.
- 대립자·선역·악역은 역할값이 아니라 태그와 서사적 기능으로 기록한다.
- 11번 아이템, 16번 특성, 17번 능력, 18번 클래스, 20번 인물은 `미세단위 제작 기능`으로 묶는다.
- 기존 시리즈별 설정 문서와 기존 프롬프트 데이터는 이번 작업에서 이동하지 않는다.
- 커밋과 푸시는 마스터의 별도 요청이 있을 때만 수행한다.
