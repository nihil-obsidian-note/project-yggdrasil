## 개요

이 작업은 룩스테라의 기존 `검토 자료`와 `설정 정비`를 하나의 추적 가능한 설정 정비 체계로 통합한 이관 기록이다. 이관 과정에서 설정 정본을 변경하지 않았으며, 변경 계획과 적용·검증 이력을 정본과 구분해 보존한다.

완료 판정은 기존 자료의 정보 보존, 구 경로 제거, 정비 문서 메타데이터, 중앙 현황, 위키 링크와 지침 반영을 모두 검증한 뒤에만 내린다.

## 대상 문서

- `룩스테라/검토 자료/`의 기존 작업 기록 4개
- `룩스테라/설정 정비/`의 기존 작업 문서 3개
- `룩스테라/설정 정비/설정 정비 현황.md`
- 프로젝트 루트 `AGENTS.md`, `문서 작성 및 수정 지침.md`, `룩스테라/AGENTS.md`

## 발견 사항

기존 자료는 검토 결과, 변경 내역, 검증 보고서, 미완료 작업 목록이 두 폴더에 나뉘어 있었고, `progress`와 `작성완료`가 실제 정본 반영 완료와 구분되지 않았다. 범용 파일명과 내용 없는 자리표시자는 후속 작업의 범위와 상태를 추적하기 어렵게 했다.

## 정비 항목

- [x] 기존 자료를 작업명 기준으로 이관·병합·이름 변경
- [x] 중앙 현황 문서와 상태값 체계 생성
- [x] 독립 미해결 사항을 후속 정비 문서로 분리
- [x] 공통·룩스테라 지침에 중앙 현황 확인과 상태 규칙 반영
- [x] 구 경로, 메타데이터, UUID, 위키 링크, 현황 일치 여부 검증
- [x] 사용자 적용용 ZIP과 이관·삭제 매핑 작성

## 적용 내역

- 정치체제 적용 기록과 검증 보고서를 `룩스테라 정치체제 및 갈등관계 정비`로 병합했다.
- 카르코사 정비, 자유 탐사 연맹 지부 반영, 자연·원소 신격 분류, 신격 신앙 형태 조정 문서를 작업명과 상태 체계에 맞게 이관했다.
- 프로스트 앵커 소속 표현과 오벨리스·길드스톤 분류를 각각 독립 정비 문서로 분리했다.
- 실질 내용과 역참조가 없는 `문서.md`를 폐기 이력으로 남기고 제거했으며, 모든 유효 자료 이관 뒤 `검토 자료` 폴더를 제거했다.

## 검증 결과

2026년 7월 23일에 설정 정비 문서 9개를 검사했다. 허용되지 않은 상태값은 0건이었고, `완료`와 `completed_at`의 불일치는 0건, 설정 정비 문서 안의 위키 링크 누락은 0건이었다. `설정 정비` 폴더에는 `progress` 필드가 남아 있지 않으며, `검토 자료` 폴더는 유효 자료 이관 뒤 비어 있음을 확인하고 제거했다.

저장소 전체의 `progress`와 `작성완료` 검색 결과 중 스토리 설계 문서와 그 규칙, 이관 이력을 설명하는 정비 문서의 역사적 언급은 유지했다. 이는 설정 정비의 현재 메타데이터가 아니며, 룩스테라 설정 정비 문서에는 적용되지 않는다. `git diff --check`도 통과했다.
