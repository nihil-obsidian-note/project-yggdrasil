## 개요

이 작업은 룩스테라 문서에 남은 이미지 경로를 정본 폴더 구조와 대조하고, 잘못된 경로를 실제 존재하는 이미지 파일 경로로 정리하는 작업이다. 이미지 임베드와 `thumbnail` 프런트매터는 문서의 설정 사실이 아니라 참조 경로이므로, 정본 내용이나 이미지 파일 자체를 임의로 새로 만들지 않는다.

경로가 `시리즈/룩스테라`로 시작하는 표기는 정본 경로가 아니다. 룩스테라 이미지의 기준 경로는 `프로젝트 위그드라실/룩스테라/이미지/{설정/신격/용종 도감}/<파일이름>`이며, 문서의 유형과 실제 저장 위치를 함께 확인해 적용한다.

## 대상 문서

룩스테라 아래의 공개 설정, 신격, 용종 도감과 그 밖에 이미지 임베드 또는 `thumbnail` 값을 가진 모든 Markdown 문서가 대상이다. 이미지 정본은 `룩스테라/이미지/설정`, `룩스테라/이미지/신격`, `룩스테라/이미지/용종 도감` 아래의 실제 파일로 판정한다.

문서에 적힌 경로 문자열만 바꾸지 않는다. 각 후보 경로를 실제 파일과 대조하고, 파일이 없거나 복수 후보가 있는 경우에는 임의 치환하지 않고 미해결 목록으로 남긴다.

## 적용 내역

빙막룡 네르카스 문서에 노멀폼 전신 이미지를 `thumbnail`으로 적용하고, 노멀폼 전신·초상화와 아이스폼 전신·초상화 이미지 네 장을 본문 최상단에 배치했다. 네 파일은 모두 `이미지/용종 도감`의 실제 파일과 대조했으며, 아이스폼은 빙막 활성화 상태로 본문에 명시했다.

실제 설정 문서에서 비어 있지 않은 `thumbnail` 176건을 전수 확인했다. 그중 구버전 `시리즈/룩스테라/` 접두어를 사용한 172건은 대응하는 실제 이미지 파일이 모두 존재하는 것을 확인한 뒤, 정본 `프로젝트 위그드라실/룩스테라/` 접두어로 교체했다. 이미 정본 경로를 사용하던 4건과 빈 `thumbnail` 209건은 임의로 변경하지 않았다. `AGENTS.md`의 경로 예시는 문서 썸네일 집계에서 제외했다.

실제 적용 단계에서는 문서 유형·이미지 파일명·저장 폴더를 함께 대조한다. 동일 파일명이 서로 다른 이미지 폴더에 있을 가능성도 있으므로, 파일명만으로 경로를 자동 확정하지 않는다.

## 검증 결과

구버전 `thumbnail` 접두어는 0건이 남았으며, 이번에 수정한 172개 경로는 모두 실제 이미지 파일을 가리킨다. `AGENTS.md`의 `<파일명>` 경로는 문서 경로 예시이므로 실제 썸네일 오류로 집계하지 않았다.

2026-07-24 재점검에서 실제 설정 문서의 비어 있지 않은 `thumbnail` 176건이 모두 `프로젝트 위그드라실/룩스테라/이미지/{설정/신격/용종 도감}/<파일이름>` 형식이고, 대응하는 이미지 파일도 실제로 존재함을 확인했다. 빈 값 209건은 경로 오류가 아니며, 지침 문서는 설정 문서 집계에서 제외했다.

본문 이미지 임베드 275건도 전수 대조했다. 모든 대상이 실제 정본 이미지 파일과 대응했고, 구버전 `시리즈/룩스테라/이미지/` 접두어를 `프로젝트 위그드라실/룩스테라/이미지/`로 정정했다. 이로써 썸네일과 본문 임베드 경로 정비를 완료한다.

## 미해결 사항

빈 `thumbnail` 209건은 이번 경로 정합성 정비 범위에서 제외했다. 이 값들은 이미지 후보를 실제로 확인한 뒤에만 채울 수 있으므로, 파일명만으로 자동 추가하지 않는다. 경로 정합성 기준의 미해결 사항은 없다.
