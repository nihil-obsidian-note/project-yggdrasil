## 개요

이 작업은 룩스테라 문서에 남은 이미지 경로를 정본 폴더 구조와 대조하고, 잘못된 경로를 실제 존재하는 이미지 파일 경로로 정리하는 작업이다. 이미지 임베드와 `thumbnail` 프런트매터는 문서의 설정 사실이 아니라 참조 경로이므로, 정본 내용이나 이미지 파일 자체를 임의로 새로 만들지 않는다.

경로가 `시리즈/룩스테라`로 시작하는 표기는 정본 경로가 아니다. 룩스테라 이미지의 기준 경로는 `프로젝트 위그드라실/룩스테라/이미지/{설정/신격/용종 도감}/<파일이름>`이며, 문서의 유형과 실제 저장 위치를 함께 확인해 적용한다.

## 대상 문서

룩스테라 아래의 공개 설정, 신격, 용종 도감과 그 밖에 이미지 임베드 또는 `thumbnail` 값을 가진 모든 Markdown 문서가 대상이다. 이미지 정본은 `룩스테라/이미지/설정`, `룩스테라/이미지/신격`, `룩스테라/이미지/용종 도감` 아래의 실제 파일로 판정한다.

문서에 적힌 경로 문자열만 바꾸지 않는다. 각 후보 경로를 실제 파일과 대조하고, 파일이 없거나 복수 후보가 있는 경우에는 임의 치환하지 않고 미해결 목록으로 남긴다.

## 정비 항목

- [ ] 전 문서의 `thumbnail`과 이미지 임베드 경로 전수 추출
- [ ] `시리즈/룩스테라`로 시작하는 비정본 경로 식별
- [ ] 이미지 유형별 실제 파일 존재 여부와 정본 경로 대조
- [ ] 확인된 경로만 `프로젝트 위그드라실/룩스테라/이미지/{설정/신격/용종 도감}/<파일이름>` 형태로 수정
- [ ] 수정 후 임베드·프런트매터 경로와 실제 파일의 일치 재검증

## 적용 내역

아직 점검하거나 수정하지 않음. 이 문서는 이미지 경로 전수 정비를 시작하기 전의 범위와 판정 기준을 등록한 기록이다.

실제 적용 단계에서는 문서 유형·이미지 파일명·저장 폴더를 함께 대조한다. 동일 파일명이 서로 다른 이미지 폴더에 있을 가능성도 있으므로, 파일명만으로 경로를 자동 확정하지 않는다.

## 검증 결과

아직 검증하지 않음. 완료 판정은 모든 후보 경로가 실제 이미지 파일과 대조되고, 수정한 경로의 임베드와 `thumbnail` 값이 모두 정본 위치를 가리키는지 확인한 뒤에만 내린다.

## 미해결 사항

전수 조사 전에는 비정본 경로의 실제 건수와 누락 이미지 파일 수를 알 수 없다. 존재하지 않는 파일, 복수 후보, 문서 유형과 이미지 폴더가 맞지 않는 사례는 각각 분리해 후속 판단을 받는다.
