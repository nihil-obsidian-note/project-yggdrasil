## 개요

이 작업은 룩스테라 `설정/` 아래 Markdown 문서 전체를 새 문단 기준으로 다시 점검하고, 결과에 따라 문서군별 보강·구조 정리·재검증을 관리한다. 국가 문서 정비는 이 작업 안의 하위 범위가 아니라, 이미 진행 중인 별도 작업으로 유지하며 서로의 결과와 적용 이력을 대조한다.

2026년 7월 24일의 최신 토큰 누락 전수 점검 결과를 기준으로 작업 범위를 다시 등록함에 따라 이 문서는 폐기한다. 이후 적용과 검증은 [[룩스테라 설정 토큰 누락 전수 정비]]에서 일원화한다.

점검기는 `##`부터 `######`까지 모든 제목을 독립 섹션으로 판정한다. 각 실질 서술 문단은 문장 수와 무관하게 최소 100토큰, 각 실질 섹션은 최소 두 문단과 총 300토큰을 충족해야 하며, 하위 제목의 본문은 상위 제목의 분량에 합산하지 않는다.

## 대상 문서

2026년 7월 23일 기준 `룩스테라/설정/`의 Markdown 문서 151건이 대상이다. 국가·도시국가·부족국가·대륙·지형·단체·개념·인물·종족·사건·아이템·설화 등 실제 문서 유형을 모두 포함한다.

템플릿 문서와 설정 정비 문서는 이 전수 측정의 대상이 아니다. 설정 사실을 보강할 때에는 해당 문서의 템플릿, 관련 인덱스, 정본, 세력 관계 문서를 먼저 대조하며, 설정 정비의 조사 결과를 정본 사실처럼 인용하지 않는다.

## 분석 결과

전체 세부 결과는 [[룩스테라 설정 문서 전수 재점검 보고서]]에 보관한다. 이 보고서에는 151개 문서 각각의 점검 요약과 제목 단계별 문단 수, 산문 토큰 수, 300토큰 대비 부족분, 100토큰 미만 문단 수, 강제 줄바꿈·목록·표·하위 제목 여부, 판정이 빠짐없이 기록되어 있다.

새 기준으로는 이전에 통과로 보였던 문서도 하위 제목 본문을 상위 섹션에 합산할 수 없으므로 재판정된다. 카르키논의 통치 구조처럼 짧은 문단과 하위 제목을 묶어 상위 섹션 분량으로 계산하던 사례는 각 제목의 직접 본문을 분리해 다시 정리한다.

## 적용 내역

문장 수가 아니라 문단 토큰 수로 판정하도록 점검기를 수정했다. 실질 서술 문단은 100토큰 미만이면 부족으로 기록하며, 문장 하나가 길거나 여러 문장으로 이루어졌다는 사실만으로 예외를 두지 않는다.

점검기는 모든 제목 단계를 독립 섹션으로 분리한다. 이 변경으로 하위 제목의 분량을 상위 섹션에 중복 합산하지 않으며, 상위 제목 아래의 직접 본문이 부족한 경우를 별도로 드러낸다.

## 검증 결과

전수 보고서의 문서 수는 실제 `설정/` Markdown 문서 수와 같은 151건이다. 보고서의 상세 판정 행은 1,696건이며, 각 문서의 `항목`은 템플릿 예외로 표시하되 내용 감지 여부는 별도로 남긴다.

이 수치는 보강 전 진단값이다. 이후 문서를 수정하면 해당 문서와 관련 정본을 다시 읽고, 동일 점검기로 재측정한 결과를 이 작업 문서와 상세 보고서의 후속 이력에 반영한다.

## 미해결 사항

전수 측정 결과를 문서 유형·결손 형태·관련 정본의 밀집도에 따라 묶는 우선순위 설계가 남아 있다. 문서 수만으로 순서를 정하지 않고, 같은 정본·관계 문서를 공유해 함께 검증할 수 있는 문서군을 우선 단위로 삼는다.
