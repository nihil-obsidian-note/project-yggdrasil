## 사용 원칙

이 라이브러리는 라크샤라의 [[용종]]을 새로 설계하거나 기존 용종의 이름을 점검할 때 사용하는 명명 기준이다. 용종의 정식 명칭은 기본적으로 `별칭 + 고유명`의 두 부분으로 구성하며, 별칭은 현장에서 생태와 외형을 압축해 부르는 도감명이고 고유명은 해당 종을 다른 종과 구별하는 고유 어휘다. `뇌명조 그라바크`, `회염룡 자르간`처럼 별칭만으로 대표 특징과 생물형을 짐작할 수 있고, 고유명만으로도 짧고 분명하게 호명할 수 있어야 한다. 별칭은 설명문을 줄인 장식어가 아니며, 고유명은 별칭을 외국어처럼 다시 번역한 단어가 아니다.

몬스터 헌터 계열의 명명 사례는 짧은 한자어 별칭이 속성·기관·행동·생물형을 압축하는 방식을 분석하기 위한 참고 자료로만 사용한다. 기존 몬스터의 별칭이나 고유명을 그대로 가져오거나 한 글자만 바꾸어 재사용하지 않는다. 룩스테라에서는 분류명과 별칭을 분리하고, 이미 확정된 [[용종]]의 분류 정의와 라크샤라 생태를 우선하여 독자적인 조립 규칙으로 운용한다. 외부 사례와 충돌하거나 룩스테라 정본에서 다른 의미가 확정된 경우에는 정본을 우선하고 이 라이브러리를 후속 갱신한다.

## 기본 명칭 구조

정식 표기는 `별칭 고유명` 순서로 작성한다. 별칭은 한자어 음독을 기준으로 2~4음절을 사용하며 3음절을 표준으로 삼는다. 고유명은 3~5음절을 사용하며 3~4음절을 표준으로 삼는다. 별칭과 고유명을 합친 전체 이름은 한 호흡으로 읽히되, 두 요소의 경계가 분명해야 한다. 파일명과 문서 제목에는 한글 표기만 사용하고, 한자가 필요한 경우 본문의 최초 정의에서 `회염룡(灰焰龍)`처럼 병기한다. 일본식 약자 `竜` 대신 한국 한자 표기인 `龍`을 사용하며, 한글 음독은 합성어의 종결 위치에서 `룡`으로 통일한다.

별칭은 보통 `대표 특징 + 생물형 종결어`로 조립한다. 대표 특징에는 속성, 분비 기관, 두드러진 신체 구조, 사냥 행동, 서식 환경, 색과 재질 가운데 한두 축만 선택한다. `회염룡`은 재와 불꽃, `뇌명조`는 천둥 같은 울음과 조류형을 결합한 사례다. 세 개 이상의 독립적인 특징을 한 별칭에 밀어 넣지 않으며, 별칭에서 이미 드러난 의미를 고유명에서 반복하지 않는다. `빙설냉수사룡`처럼 속성어를 중첩하거나 `회염룡 이그니스`처럼 고유명까지 불을 직접 뜻하게 만드는 구조는 피한다.

권장 기본식은 다음과 같다.

- `속성 1음절 + 기관·행동 1음절 + 종결어 1음절`: 회염룡, 뇌명조, 빙조룡
- `색·재질 1음절 + 생물 모티브 1음절 + 종결어 1음절`: 흑랑룡, 백각수, 수정해
- `핵심 행동 1~2음절 + 종결어 1음절`: 교사룡, 폭추룡, 잠구룡
- `환경 1음절 + 현상 1음절 + 종결어 1음절`: 사해룡, 설조룡, 무빙룡
- `속성·기관 2음절 + 복합 종결어 2음절`: 빙인어룡, 풍익룡, 균사룡

## 별칭 설계 우선순위

별칭을 만들 때에는 가장 먼저 그 종을 현장에서 식별하게 만드는 특징을 고른다. 단순히 화염을 사용한다는 이유만으로 모두 `화룡`이나 `염룡`으로 부르지 않는다. 같은 화염 계통이라도 재를 뿌린 뒤 점화하면 `회염`, 폭발성 체액을 터뜨리면 `폭유`, 용암을 몸에 두르면 `용암`, 고열의 날개막이 핵심이면 `열익`처럼 작동 방식과 기관을 구분한다. 속성은 시작점일 뿐이며, 별칭은 해당 속성이 생태 안에서 어떻게 발현되는지를 보여 주어야 한다.

두 번째 우선순위는 생물의 실루엣과 핵심 기관이다. 분류가 사룡종이라고 해서 별칭을 `빙류사`처럼 `사`로 끝내지 않으며, 뱀형 생물을 뜻하는 글자는 종결어 앞에 배치하여 `수사룡`, `교사룡`처럼 구성한다. 갑각종의 게형 개체는 `해(蟹)`, 갑충종의 벌형 개체는 `봉(蜂)`, 협각종의 거미형 개체는 `지주(蜘蛛)`처럼 실제 생물형을 종결어로 사용할 수 있다. 분류명은 학술적 범주이고 종결어는 현장에서 보이는 형상을 압축한 말이므로, 둘이 반드시 같은 글자를 공유할 필요는 없다.

별칭 후보를 비교할 때에는 다음 순서로 판정한다.

1. 이름만 듣고 대표 생태나 기관을 한 가지 이상 추론할 수 있는가.
2. 종결어가 실제 실루엣과 생물 기반에 맞는가.
3. 같은 분류의 기존 용종과 첫 두 음절이 겹치지 않는가.
4. 속성만 바꾼 양산형 이름처럼 보이지 않는가.
5. 한자 뜻을 설명했을 때 본문 설정과 모순되지 않는가.
6. 고유명과 이어 읽었을 때 발음이 뭉개지지 않는가.

## 분류별 종결어

종결어는 분류표의 글자를 기계적으로 복사하지 않고, 해당 개체의 외형과 생태를 함께 고려하여 선택한다. 다만 비룡종·수룡종·해룡종·아룡종·어룡종·사룡종은 용형 생물이라는 인상이 강하므로 `룡`을 기본 종결어로 사용한다. 조룡종은 조류형과 지상 군집형을 구분하고, 절지동물·양서류·포유류 기반 분류는 생물형을 직접 나타내는 종결어를 우선한다. 아래의 `기본`은 특별한 이유가 없을 때 적용하는 형식이며, `조건부`는 외형이 명확하고 이름만으로 오해가 생기지 않을 때 사용한다.

같은 종결어가 서로 다른 분류에서 나타날 수 있다. `랑룡`은 늑대형 실루엣을 지닌 아룡종에 적합하지만, 포유류 기반 아수종이라면 `랑`이나 `수`로 끝낼 수 있다. `해`는 바다를 뜻하는 `海`가 아니라 게를 뜻하는 `蟹`로 사용할 수 있으므로 한자 병기를 통해 의미를 고정한다. 룩스테라의 명명 체계에서는 한 종 안에서 한자음식 종결어와 순우리말 종결어를 섞지 않으며, 게형 갑각종은 `~해`, 거미형 협각종은 `~지주`로 통일한다.

| --- | --- | --- | --- |
| 조룡종 | `~조(鳥)` | `~룡(龍)` | 단독 생활·비행·명확한 조류형은 `조`, 지상 질주·군집·수각류형은 `룡` |
| 비룡종 | `~룡(龍)` | 없음 | 날개와 비행, 브레스 기관을 가진 대표 용형이므로 고정 |
| 수룡종 | `~룡(龍)` | 없음 | 짐승 수(獸) 분류지만 별칭은 이족보행 용형을 따라 `룡`으로 고정 |
| 해룡종 | `~룡(龍)` | `~수(獸)` | 길고 유동적인 용형은 `룡`, 짐승형 얼굴과 행동이 압도적일 때만 `수` |
| 아룡종 | `~룡(龍)` | 없음 | 늑대·도마뱀·포식자 모티브는 `랑룡`, `호룡`, `적룡`처럼 종결부에 삽입 |
| 어룡종 | `~룡(龍)` | `~어룡(魚龍)` | 물고기 형질을 강조해야 할 때 `어룡`, 환경만 물인 경우에는 단순 `룡` |
| 사룡종 | `~룡(龍)` | `~사룡(蛇龍)` | 마지막은 반드시 `룡`; 뱀 형질을 직접 강조할 때 `사`를 종결어 앞에 배치 |
| 익룡종 | `~익룡(翼龍)` | `~룡(龍)` | 경량 활강형·막날개를 명시할 때 `익룡`, 다른 기관이 더 강할 때 단순 `룡` |
| 초식종 | `~수(獸)` | `~룡`, `~록(鹿)`, `~우(牛)`, `~상(象)` | 포유 초식형은 `수`, 공룡형은 `룡`, 특정 동물 실루엣이 명확하면 개별 종결어 |
| 아수종 | `~수(獸)` | `~저(猪)`, `~웅(熊)`, `~원(猿)`, `~호(虎)`, `~랑(狼)`, `~사자(獅子)` | 포유류 기반을 직접 표시하며 용형 종결어를 억지로 붙이지 않음 |
| 양서종 | `~와(蛙)` | `~원(螈)`, 생물 고유형 | 개구리·두꺼비는 `와`, 도롱뇽·영원형은 `원`; 독·점액은 앞부분에서 표현 |
| 갑각종 | `~해(蟹)` | `~하(蝦)`, `~패(貝)` | 게형은 `해`, 새우·가재형은 `하`, 고착성 껍질 군체는 `패` |
| 갑충종 | `~충(蟲)` | `~갑충`, `~봉(蜂)`, `~당랑(螳螂)`, `~접(蝶)`, `~아(蛾)`, `~오공(蜈蚣)` | 곤충·다족류의 실제 모티브가 명확할수록 구체 종결어 사용 |
| 협각종 | `~지주(蜘蛛)` | `~갈(蠍)`, `~비(蜱)` | 거미는 `지주`, 전갈은 `갈`, 진드기형은 드물게 `비`; `해`는 사용하지 않음 |
| 두족종 | `~소(蛸)` | `~오적(烏賊)`, `~룡` | 문어형은 `소`, 오징어·갑오징어형은 `오적`, 용형 실루엣이 강할 때만 `룡` |
| 식생종 | `~룡(龍)` | `~목룡`, `~화룡`, `~균룡`, `~등룡` | 단독 식물명보다 용종임을 드러내는 복합 종결어를 사용하며 동음이의어를 피함 |
| 고룡종 | 기존 종결어 유지 | 신규 발견 시 원계통 기준 | 혈통 분류가 아닌 위상이므로 고룡종이 되었다는 이유로 별칭을 바꾸지 않음 |

## 분류별 세부 적용

조룡종에서는 조류형과 지상 군집형의 구분이 가장 중요하다. 날개·깃털·부리·독립 영역을 가진 대형 조류형은 `뇌명조`, `독요조`, `산조`처럼 `조`로 끝낸다. 날개가 퇴화하고 두 다리로 질주하며 무리를 이루는 수각류형은 `구룡`, `독구룡`, `면구룡`처럼 `룡`으로 끝낼 수 있다. 룩스테라에서는 단순히 무리를 이룬다는 사실 하나만으로 종결어를 바꾸지 않고, 몸의 실루엣과 이동 방식까지 함께 본다. [[뇌명조 그라바크]]는 대형 조류 기반이며 독립 영역을 유지하므로 `조`가 적합하다.

비룡종·수룡종·해룡종·아룡종·어룡종·사룡종은 기본적으로 `룡`을 유지하되, 종결어 앞의 글자가 분류의 개성을 담당한다. 비룡종은 날개·불꽃·폭격·발톱, 수룡종은 턱·꼬리·돌진·폭발, 해룡종은 조수·거품·진흙·수압, 아룡종은 늑대·도마뱀·발톱·집단 사냥, 어룡종은 비늘·지느러미·진흙·모래 유영, 사룡종은 조이기·목의 피막·독·지중 잠행을 우선한다. `회염룡 자르간`은 비룡종이라는 분류 자체보다 재구름과 점화 기관이 핵심이므로 `비룡`을 별칭에 반복하지 않고 `회염룡`으로 압축한다.

절지동물·양서류·포유류 기반 분류에서는 `룡`보다 생물형 종결어가 더 강한 식별력을 가진다. 게형 갑각종을 `○○룡`으로 부르면 갑각의 모티브가 사라지지만 `○○해`로 부르면 집게와 등갑을 즉시 떠올릴 수 있다. 거미형 협각종은 `지주`, 문어형 두족종은 `소`, 개구리형 양서종은 `와`, 곰·원숭이형 아수종은 `수`나 구체 동물명을 사용한다. 다만 식생종은 `목`이나 `화`만으로 끝내면 일반 식물명처럼 보이므로 `균사룡`, `독화룡`, `철등룡`처럼 용종임을 드러내는 복합 종결어를 우선한다.

## 한자와 음독 규칙

별칭의 한자는 뜻을 고정하고 동음이의어를 구분하기 위한 보조 표기다. 한글로 읽었을 때 같은 `해`라도 `海`는 바다이고 `蟹`는 게이며, 같은 `화`라도 `火`는 불이고 `花`는 꽃이다. 이름을 확정할 때에는 한글 별칭과 함께 한자를 정하고, 본문 최초 등장이나 도감의 명칭 항목에서 한 번 병기한다. 파일명·링크·대화상 호칭은 한글로 유지하여 검색성과 가독성을 지킨다. 사용하려는 한자의 실제 음과 뜻을 확인하지 않은 채 분위기만으로 조합하지 않는다.

한자 조합은 일반 독자가 풀이를 들었을 때 납득할 수 있어야 한다. 너무 희귀한 글자를 사용해 매번 주석이 필요하거나, 한국 한자음과 다른 임의 독음을 붙이거나, 의미가 겹치는 글자를 나란히 쌓는 방식은 피한다. `빙결룡`처럼 빙과 결이 모두 얼음을 뜻하더라도 한쪽이 작동을 구체화한다면 사용할 수 있으나, `빙동결한룡`처럼 같은 뜻이 반복되면 탈락시킨다. 종결어가 두 음절인 `익룡`, `어룡`, `지주`, `당랑`, `오공`, `오적`은 앞부분을 한두 음절로 제한하여 전체 별칭이 4음절을 넘지 않게 한다.

자주 사용할 수 있는 글자 축은 다음과 같다. 이 목록은 조합 재료이며, 여기에 있다는 이유만으로 설정 없이 붙이지 않는다.

- 속성·현상: 화(火), 염(炎·焰), 회(灰), 뇌(雷), 빙(氷), 동(凍), 수(水), 조(潮), 무(霧), 풍(風), 독(毒), 산(酸), 광(光), 영(影), 혈(血)
- 환경·재질: 사(沙), 암(岩), 니(泥), 설(雪), 해(海), 천(泉), 정(晶), 철(鐵), 은(銀), 금(金), 흑(黑), 백(白), 창(蒼), 홍(紅), 취(翠)
- 기관·형질: 아(牙), 각(角), 익(翼), 갑(甲), 각(殼), 조(爪), 겸(鎌), 미(尾), 관(冠), 막(膜), 극(棘), 인(鱗), 지(鰭)
- 행동·생태: 교(絞), 폭(爆), 추(鎚), 잠(潛), 천(穿), 열(裂), 명(鳴), 식(食), 전(纏), 상(翔), 분(噴), 흡(吸), 유(流)
- 식생 계통: 목(木), 화(花), 균(菌), 사(絲), 등(藤), 근(根), 포(胞), 엽(葉)

## 고유명 작성 규칙

고유명은 별칭과 달리 한자 뜻을 압축하는 부분이 아니라 종 자체를 고유하게 식별하는 이름이다. 라크샤라 용종의 고유명은 3~5음절, 기본 3~4음절로 만들며, 자음과 모음의 대비가 분명하고 한글로 한 번 읽었을 때 다시 발음할 수 있어야 한다. `그라바크`, `자르간`처럼 강한 자음과 열린 모음을 섞을 수 있지만 모든 이름을 `-크`, `-간`, `-곤`으로 끝내지는 않는다. 같은 분류나 같은 지역의 이름에 공통 음운을 약하게 부여할 수 있으나, 종마다 서로 다른 실루엣과 생태가 있으므로 일괄적인 접미사 체계로 만들지 않는다.

고유명은 실제 언어의 단어를 그대로 사용하거나 유명한 판타지·게임 몬스터 이름을 변형하여 만들지 않는다. 후보를 확정하기 전에는 룩스테라 전체에서 동일·유사 고유명을 검색하고, 국가·도시·인물·신격·용종과 충돌하지 않는지 확인한다. 첫 음절과 마지막 음절만 다른 이름도 발음이 유사하면 충돌 후보로 본다. 별칭이 부드러운 음절로 끝나면 고유명 첫소리를 강하게, 별칭이 폐쇄음과 겹받침이 많으면 고유명의 시작을 열린 모음으로 조정하는 등 전체 호흡도 함께 점검한다.

고유명 후보는 다음 기준으로 거른다.

- 한글 표기만 보아도 하나의 발음으로 읽히는가.
- 별칭의 마지막 음절과 고유명의 첫 음절이 반복되어 더듬거리지 않는가.
- 기존 룩스테라 고유명과 두 음절 이상 연속으로 겹치지 않는가.
- 속성의 외국어 번역을 그대로 사용하지 않았는가.
- 지나치게 사람 이름이나 국가 이름처럼 들리지 않는가.
- 유체·성체·암수에 관계없이 종 전체를 가리킬 수 있는가.

## 원종·아종·지역 변종의 명명

원종은 기본 `별칭 + 고유명`을 사용한다. 아종은 색만 달라진 개체가 아니라 속성 기관, 서식지, 사냥법, 생태적 역할이 안정적으로 달라진 집단이므로 차이가 별칭에 드러날 때만 새로운 별칭을 부여한다. 원종과 고유명을 공유하는 계통이라면 `새 별칭 + 기존 고유명 아종`으로 기록할 수 있고, 독립된 종으로 분리될 만큼 차이가 크면 별칭과 고유명을 모두 새로 만든다. 색채 변화만으로 별칭을 바꾸지 않으며, 색이 실제 위장·체온·번식·속성 기관의 변화를 나타낼 때에만 색 글자를 사용한다.

지역 변종은 먼저 기존 고유명과 별칭을 유지하고 도감에서 지역 변종으로 표시한다. 장기간 격리되어 기관과 생태가 달라졌다는 근거가 축적되면 별칭의 앞부분을 바꾸거나 별도의 고유명을 부여할 수 있다. `고원형`, `해안형` 같은 편집용 표현을 정식 이름에 그대로 넣지 않으며, 지역명이 별칭을 차지하려면 그 지역의 환경이 개체의 핵심 기관을 실제로 바꾸어야 한다. 성장 단계와 성별 차이, 일시적인 용성 과잉, 계절색은 아종이나 새 종으로 명명하지 않는다.

고룡종과 재해룡종은 별도의 혈통 분류가 아니므로 상태가 바뀌었다는 이유만으로 이름을 교체하지 않는다. 조룡종 개체가 오랜 세월 용성을 축적해 고룡종 위상을 얻어도 기존 별칭과 고유명을 유지하고 도감 분류에 `조룡종·고룡종 위상`을 함께 기록한다. 잔향에 침식된 재해룡종도 원래 이름을 유지한 채 재해룡종 지정을 별도로 붙인다. 변질 상태가 세대를 거쳐 안정적인 독립종으로 굳었다는 근거가 생기기 전에는 `재해`, `흉`, `멸` 같은 글자를 앞에 붙여 새 이름으로 승격하지 않는다.

## 제작 절차

용종 이름은 외형이 완성된 뒤 장식처럼 붙이는 것이 아니라, 생태 설계와 함께 결정한다. 먼저 분류와 원생 생물, 대표 서식지, 이동 방식, 먹이와 사냥법, 핵심 용성 기관, 주변 생태에 주는 영향을 한 문장씩 정리한다. 그다음 현장에서 가장 먼저 발견되는 흔적과 가장 위험한 기관을 각각 하나 고르고, 속성·기관·행동·환경 가운데 어느 축이 종의 정체성을 가장 잘 설명하는지 판정한다. 이 단계에서 분류만 정해졌고 기관과 생태가 비어 있다면 이름을 확정하지 않는다.

별칭은 최소 10개, 고유명은 최소 10개를 독립적으로 만든 뒤 조합한다. 별칭 후보는 종결어의 적합성, 의미 중복, 기존 별칭과의 충돌을 먼저 거르고, 고유명 후보는 발음·중복·지역 어감으로 거른다. 살아남은 별칭과 고유명을 임의로 1대1 대응하지 말고, 서로 이어 읽었을 때의 리듬과 자음 충돌을 비교한다. 최종 후보는 3~5개만 남겨 각각 한자 풀이, 핵심 설정과의 연결, 오인 가능성을 함께 제시한다.

명명 작업의 실행 순서는 다음과 같다.

1. [[용종]]과 대상 분류 정의를 확인한다.
2. 대상 생태권과 관련 용성 속성 정본을 읽는다.
3. 원생 생물·실루엣·이동·기관·행동·생태 역할을 한 줄씩 정리한다.
4. 별칭의 대표 축을 하나, 보조 축을 하나 선택한다.
5. 분류별 종결어 표에서 기본 종결어를 선택한다.
6. 2~4음절 별칭 후보를 최소 10개 만든다.
7. 3~5음절 고유명 후보를 최소 10개 만든다.
8. 기존 문서 전체에서 동일·유사 명칭을 검색한다.
9. 의미·발음·한자·분류·생태 정합성을 검증한다.
10. 사용자가 확정한 이름만 정본 문서와 도감에 반영한다.

## 금지 규칙과 교정 예시

분류명을 곧바로 별칭의 종결어로 오해하지 않는다. `사룡종`은 뱀 계통의 분류명이지만 `빙류사`처럼 `사`로 끝내지 않고 `빙조룡`, `수사룡`, `동파룡`처럼 마지막을 `룡`으로 둔다. `수룡종`의 수는 물 수가 아니라 짐승 수이므로 물 속성을 자동으로 부여하지 않는다. `해룡종`이라고 해서 모든 별칭을 `○○해룡`으로 만들지 않으며, 게형 갑각종의 `해(蟹)`와 바다의 `해(海)`를 한글 표기만으로 혼동하지 않도록 한자를 확인한다.

이름을 강하게 보이게 하려고 파괴·멸망·왕·신·황제 같은 위상어를 남발하지 않는다. 일반 원종에 `멸천황룡`, `신살룡`, `재앙왕` 같은 말을 붙이면 생태적 식별명보다 전투 등급이나 서사적 칭호처럼 보인다. 별칭은 강함의 순위를 나타내지 않고 관찰 가능한 특징을 나타낸다. 고룡종 위상이나 특정 개체의 전승상 칭호가 필요하면 종 전체의 정식 이름과 분리해 기록한다.

| 잘못된 형식 | 문제 | 교정 방향 |
| --- | --- | --- |
| 빙류사 | 사룡종의 `사`를 종결어로 오해 | 빙조룡, 동파룡, 수사룡 |
| 화염불룡 | 같은 의미를 반복 | 화룡, 염각룡, 회염룡 |
| 냉기물뱀룡 | 한국어 설명을 그대로 압축 | 빙조룡, 한천룡, 결류룡 |
| 비룡 자르간 | 분류명이 별칭을 대신해 개성이 없음 | 회염룡 자르간 |
| 재해회염룡 자르간 | 상태 지정이 정식 종명에 침투 | 회염룡 자르간, 재해룡종 지정 |
| 화룡 파이로스 | 별칭과 고유명이 같은 뜻을 반복 | 별칭 또는 고유명 한쪽을 비속성 의미로 교체 |
| 독화룡 | 火와 花의 뜻이 불명확할 수 있음 | 최초 정의에서 독화룡(毒花龍)처럼 한자 병기 |
| 방패게와 수정해 혼용 | 같은 체계에서 순우리말·한자음을 혼합 | 룩스테라 갑각종은 `~해(蟹)`로 통일 |

## 확정 적용 사례

[[뇌명조 그라바크]]는 조류 기반의 대형 조룡종이며, 골질 볏과 공명낭으로 천둥에 가까운 울림을 만들어 영역과 먹이의 움직임을 조절한다. `뇌명`은 단순 번개 속성보다 천둥 같은 울음과 기상 징후를 함께 압축하며, 독립 영역을 지키는 비행 조류형이므로 `조`가 적합하다. 고유명 `그라바크`는 별칭의 뜻을 반복하지 않고 거친 고원 포식자의 인상을 보완한다.

[[회염룡 자르간]]은 장거리 비행형 비룡종이며, 검은 재와 가연성 분비물을 먼저 퍼뜨린 뒤 점화하는 기관이 핵심이다. `회염`은 재와 불꽃을 결합해 일반적인 화염 브레스종과 구분하고, 비룡종의 대표 용형이므로 `룡`으로 끝난다. 고유명 `자르간`은 화염을 뜻하는 직접 번역어가 아니며 별칭과 이어 읽었을 때 자음 대비가 분명하다.

이 두 사례는 별칭이 분류명이나 속성 하나만 반복하지 않고, 실제 생태적 작동 방식과 실루엣을 함께 드러내야 한다는 기준을 보여 준다. 이후 용종 이름도 기존 사례의 음절만 바꾸어 양산하지 않고 각 종의 기관과 생태에서 새 조합을 도출한다.

## 검증 체크리스트

명칭 검증은 발음만 자연스러운지 보는 절차가 아니다. 별칭의 한자 뜻, 분류별 종결어, 생태 기관, 고유명 중복, 상태 분류를 함께 점검한다. 이름이 훌륭해 보여도 본문에서 해당 특징이 주변 생태와 행동에 연결되지 않으면 설정이 이름을 뒷받침하지 못한 것이다. 반대로 설정에 여러 특징이 있더라도 별칭에 모두 넣지 않고 가장 식별력이 높은 한두 요소만 남긴다.

최종 확정 전에는 다음 항목을 모두 통과해야 한다.

- [ ] 정식 표기가 `별칭 + 고유명` 순서인가.
- [ ] 별칭이 2~4음절이고 고유명이 3~5음절인가.
- [ ] 종결어가 분류와 실제 실루엣에 모두 맞는가.
- [ ] 별칭에서 핵심 기관·행동·환경 가운데 최소 한 가지가 드러나는가.
- [ ] 속성어와 의미가 중복되지 않는가.
- [ ] 한자음과 뜻이 정확하며 동음이의어가 통제되었는가.
- [ ] 기존 룩스테라 고유명·별칭과 충돌하지 않는가.
- [ ] 외부 작품의 몬스터 이름이나 별칭을 직접 모사하지 않았는가.
- [ ] 고유명이 별칭의 속성을 다른 언어로 반복하지 않는가.
