## 개요

이 작업은 설정·신격·비밀 설정 문서를 데이터베이스로 이관하기 전에 카테고리, 범용 관계 유형, 문서 간 관계의 저장 단위와 이관 기준을 확정하기 위한 프로젝트 공통 정비다.

세 문서군은 하나의 `documents` 모델에 이관한다. 관계 인스턴스는 하나의 관계 본체와 2~4개의 관계 대상 참여 레코드로 저장하며, 각 대상은 관계 안에서 의미 역할을 가진다.

## 현재 상태

범용 관계 유형 2.1~2.15를 모두 확정했다. 누적 COMMON 관계는 936개, 대상 역할은 2,813개이며 신규 관계 파트는 2.15에서 종료했다.

2.14 정보·기록·표현·의미 관계 41개는 ID 887~927, 대상 역할 152개로 확정했다. 2.15 시간·연대·순서 관계 9개는 ID 928~936, 대상 역할 27개로 확정했다. 두 파트의 이관·보류 미처리 항목은 없다.

관계 유형 v1의 전체 종료 감사를 마치고 동결했다. 전역 ID 1~936은 연속하며 대상 역할은 2,813개다. 동명 관계 8쌍은 괄호형 독립 관계로, 같은 관계 안의 역할명 중복 8건은 서로 다른 역할명으로 정정해 DB 시드 기준을 확정했다.

현재 단계는 `진행 중`이다. 다음 작업은 `프로젝트 위그드라실` 프로젝트, 룩스테라·엘드로스 월드, 월드별 카테고리 계층의 초기 적재 쿼리 작성이다.

## 확정 원칙

- 이관 대상은 `설정`, `신격`, `비밀 설정`이다.
- 비밀 설정은 문서 유형이 아니라 공개 범위 컬럼으로 제어한다.
- 문서 하나는 범용 또는 세계별 확장 카테고리 하나를 선택한다.
- 범용 카테고리는 개념·신격·국가·도시·단체·종족·인물·아이템·사건·설화·지형의 11개다.
- 룩스테라 `용종`, 엘드로스 `클래스`는 세계별 확장 카테고리다.
- 관계 본체는 하나만 저장하고 2~4개의 대상 참여 레코드를 둔다.
- 각 대상은 관계 안에서 의미 역할과 허용 카테고리를 가진다.
- 괄호형 관계는 별도 ID를 가지는 독립 relation type이다.
- 자연스러운 역방향 표시명이 없는 관계는 역방향을 만들지 않는다.
- 세계별 확장 카테고리는 범용 허용 목록에 자동 포함하지 않고 SERIES 확장 매핑으로 관리한다.
