# 프로젝트 위그드라실 범용 관계 유형 정리 — 인물·조직 관계

> 상태: 브레인스토밍 확정본  
> 범위: 소속·역할, 출신·기원, 혈연·가족, 사제·양성, 조직 위계·종속, 계승·변형·정체성 관계  
> 원칙: 관계의 주체와 대상은 모두 같은 월드의 `documents`에 등록된 문서만 허용한다.

## 1. 소속·역할 관계

| 대상 1 | 관계 | 역관계 | 대상 2 | 방향 |
| --- | --- | --- | --- | --- |
| 인물 | 소속됨 | 소속 인물 | 단체·국가 | 방향 |
| 인물 | 복무함 | 복무자 | 국가·단체·인물 | 방향 |
| 인물·단체 | 고용됨 | 고용함 | 인물·단체·국가 | 방향 |
| 인물·단체 | 파견됨 | 파견함 | 단체·국가·인물 | 방향 |
| 인물·단체 | 대표함 | 대표자 | 국가·단체·종족 | 방향 |
| 인물·단체 | 지휘함 | 지휘받음 | 인물·단체 | 방향 |
| 인물·단체 | 관리함 | 관리받음 | 단체·아이템·도시·지형 | 방향 |
| 인물·단체 | 위임받음 | 위임함 | 인물·단체·국가 | 방향 |
| 인물 | 대리함 | 대리인 | 인물·단체·국가 | 방향 |

### 설명

- `소속됨`: 정식 구성원 관계
- `복무함`: 군사·행정·가신 등 지속적인 봉사 관계
- `고용됨`: 계약에 따른 고용 관계
- `파견됨`: 원래 소속을 유지한 채 다른 주체에게 보내진 관계
- `대표함`: 다른 주체의 의사와 권위를 대신 표현하는 관계
- `지휘함`: 실제 명령 체계
- `관리함`: 운영·보존·통제 책임
- `위임받음`: 권한이나 책임을 넘겨받은 관계
- `대리함`: 다른 주체를 대신해 판단하거나 행동하는 관계

직책, 계급, 역할, 재임 기간, 정규·임시 여부는 관계 보조 속성으로 기록한다.

### 예시

```text
아르덴 → 소속됨 → 탐사 연맹
기사단장 → 지휘함 → 백은 기사단
왕국 → 파견함 → 외교 사절단
섭정 → 대리함 → 국왕
```

## 2. 출신·기원 관계

| 대상 1 | 관계 | 역관계 | 대상 2 | 방향 |
| --- | --- | --- | --- | --- |
| 인물 | 태어남 | 출생지임 | 국가·도시·지형 | 방향 |
| 인물 | 성장함 | 성장지임 | 국가·도시·지형 | 방향 |
| 인물 | 출신임 | 출신 인물 | 국가·도시·지형·단체·종족 | 방향 |
| 인물 | 귀화함 | 귀화자 | 국가·도시·단체 | 방향 |
| 인물·단체 | 망명함 | 망명처임 | 국가·도시·단체 | 방향 |
| 종족·용종 | 기원함 | 기원지임 | 국가·도시·지형 | 방향 |
| 인물·단체·국가 | 창설함 | 창설됨 | 단체·국가·도시 | 방향 |
| 단체·국가·도시 | 창설지를 둠 | 창설지임 | 국가·도시·지형 | 방향 |
| 인물·단체·종족 | 이주함 | 이주지임 | 국가·도시·지형 | 방향 |
| 인물·단체·종족 | 추방됨 | 추방함 | 국가·도시·단체 | 방향 |
| 인물·단체·종족 | 정착함 | 정착지임 | 국가·도시·지형 | 방향 |

### 설명

- `태어남`: 실제 출생 장소
- `성장함`: 유년기·수련기·생활 기반이 형성된 장소
- `출신임`: 사회적·문화적·정체성상의 출신
- `귀화함`: 다른 정치 공동체의 구성원 자격을 획득함
- `망명함`: 위협을 피해 다른 세력권으로 이동함
- `기원함`: 종족·용종이 처음 발생하거나 형성된 장소
- `창설함`: 국가·단체·도시를 세운 주체
- `창설지를 둠`: 창설이 이루어진 장소
- `이주함`: 생활권을 다른 지역으로 옮김
- `추방됨`: 본래 속한 공동체에서 강제로 배제됨
- `정착함`: 이동 후 안정적인 생활 기반을 형성함

### 예시

```text
인물 A → 태어남 → 오리진
인물 A → 성장함 → 청연
수인종 → 기원함 → 라크샤라
개척단 → 창설함 → 신도시
망명 귀족단 → 망명함 → 항구 도시국가
```

## 3. 혈연·가족 관계

| 대상 1 | 관계 | 역관계 | 대상 2 | 방향 |
| --- | --- | --- | --- | --- |
| 인물 | 부모임 | 자식임 | 인물 | 방향 |
| 인물 | 형제자매임 | 형제자매임 | 인물 | 대칭 |
| 인물 | 조상임 | 후손임 | 인물 | 방향 |
| 인물 | 배우자임 | 배우자임 | 인물 | 대칭 |
| 인물 | 약혼자임 | 약혼자임 | 인물 | 대칭 |
| 인물 | 양부모임 | 양자임 | 인물 | 방향 |
| 인물 | 파양함 | 파양됨 | 인물 | 방향 |
| 인물 | 후견함 | 피후견인임 | 인물 | 방향 |
| 인물 | 혈연임 | 혈연임 | 인물 | 대칭 |
| 인물 | 가문에 속함 | 가문 구성원임 | 단체 | 방향 |
| 인물·단체 | 계승자로 지명함 | 계승자로 지명됨 | 인물 | 방향 |
| 인물 | 의절함 | 의절당함 | 인물 | 방향 |
| 인물 | 절연함 | 절연함 | 인물 | 대칭 |

### 설명

세부 촌수나 법적 지위가 확정된 경우에는 `부모임`, `형제자매임`, `양부모임` 같은 구체 관계를 사용한다. `혈연임`은 친족이라는 사실만 확정됐고 세부 관계가 불명확할 때 사용한다.

입양 관계가 파양되더라도 기존 `양부모임 ↔ 양자임` 관계는 삭제하지 않고 종료 시점과 종료 사유를 기록한다.

`파문함 ↔ 파문당함`은 종교 공동체의 자격 박탈 의미가 중심이므로 2.11-4 가호·축복·신벌로 재분류했다. 2.2에서는 활성 relation type과 집계에서 제외한다.

### 예시

```text
인물 A → 부모임 → 인물 B
인물 C ↔ 배우자임 ↔ 인물 D
인물 E → 양부모임 → 인물 F
인물 E → 파양함 → 인물 F
```

## 4. 사제·양성 관계

| 대상 1 | 관계 | 역관계 | 대상 2 | 방향 |
| --- | --- | --- | --- | --- |
| 인물 | 스승임 | 제자임 | 인물 | 방향 |
| 인물·단체 | 교육함 | 교육받음 | 인물·단체 | 방향 |
| 인물·단체 | 양성함 | 피양성자임 | 인물·단체 | 방향 |
| 인물·단체 | 훈련함 | 훈련받음 | 인물·단체 | 방향 |
| 인물·단체 | 전수함 | 전수받음 | 인물·단체 | 방향 |
| 인물·단체 | 지도함 | 지도받음 | 인물·단체 | 방향 |
| 인물·단체 | 조련함 | 조련받음 | 종족·용종 | 방향 |

### 설명

- `스승임`: 지속적이고 정체성 있는 사제 관계
- `교육함`: 지식·학문·교양 중심의 교육
- `양성함`: 특정 역할이나 직무 수행자로 장기 육성함
- `훈련함`: 전투·기술·실무 능력을 반복 숙련시킴
- `전수함`: 비전·기술·권능·지식을 넘겨줌
- `지도함`: 사제 관계까지는 아닌 조언·감독·실무 지도
- `조련함`: 용종·비인류 등을 길들이거나 특정 용도로 훈련함

`사사함`은 `스승임 ↔ 제자임`과 중복되므로 별도 관계로 두지 않는다.

### 예시

```text
검성 → 스승임 → 견습 검사
마법 학원 → 교육함 → 마도사
기사단 → 양성함 → 견습 기사
조련사 → 조련함 → 비룡
```

## 5. 조직 위계·종속 관계

| 대상 1 | 관계 | 역관계 | 대상 2 | 방향 |
| --- | --- | --- | --- | --- |
| 단체 | 하위 조직임 | 상위 조직임 | 단체 | 방향 |
| 단체 | 산하 조직임 | 산하에 둠 | 단체·국가 | 방향 |
| 단체 | 직속됨 | 직속 조직임 | 단체·국가·인물 | 방향 |
| 단체·국가·도시 | 종속됨 | 종주함 | 단체·국가 | 방향 |
| 국가·도시 | 속국임 | 종주국임 | 국가 | 방향 |
| 단체·국가·도시 | 자치권을 가짐 | 자치권을 부여함 | 국가·단체 | 방향 |
| 단체 | 분파임 | 모체 조직임 | 단체 | 방향 |
| 단체·국가·도시 | 전신임 | 후신임 | 단체·국가·도시 | 방향 |
| 단체 | 합병됨 | 합병함 | 단체·국가 | 방향 |
| 단체·국가·도시 | 분리됨 | 분리시킴 | 단체·국가·도시 | 방향 |
| 단체·국가·도시 | 흡수됨 | 흡수함 | 단체·국가 | 방향 |
| 단체·국가·도시 | 독립함 | 독립시킴 | 단체·국가 | 방향 |

### 설명

- `하위 조직임`: 하나의 조직도 내부에 있는 계층
- `산하 조직임`: 독립성을 일부 유지하면서 상위 세력 아래에 있음
- `직속됨`: 중간 조직 없이 특정 주체의 직접 명령을 받음
- `종속됨`: 정치·경제·군사적으로 예속됨
- `속국임`: 국가 간 종속 관계
- `자치권을 가짐`: 종속 상태에서 내부 운영 권한을 유지함
- `분파임`: 사상·종교·문파·조직에서 갈라져 나옴
- `전신임`: 후신의 이전 정체성
- `합병됨`: 둘 이상의 주체가 결합함
- `분리됨`: 기존 주체에서 일부가 갈라져 나옴
- `흡수됨`: 다른 주체에 편입되어 독립성을 잃음
- `독립함`: 종속 관계에서 벗어남

### 예시

```text
지역 지부 → 하위 조직임 → 탐사 연맹
기사단 → 직속됨 → 국왕
도시국가 → 속국임 → 제국
신흥 교단 → 분파임 → 원교단
구왕국 → 전신임 → 공화국
```

## 6. 계승·변형·정체성 관계

| 대상 1 | 관계 | 역관계 | 대상 2 | 방향 |
| --- | --- | --- | --- | --- |
| 인물·단체·국가·신격 | 계승함 | 계승됨 | 인물·단체·국가·신격·아이템 | 방향 |
| 인물 | 후계자임 | 선대임 | 인물 | 방향 |
| 인물·단체·국가 | 권한을 승계함 | 권한을 승계당함 | 인물·단체·국가 | 방향 |
| 인물 | 칭호를 계승함 | 칭호 계승자임 | 인물 | 방향 |
| 인물·신격 | 환생함 | 전생임 | 인물·신격 | 방향 |
| 인물·신격·용종 | 화신임 | 본체임 | 신격·개념·용종 | 방향 |
| 인물·신격·용종 | 분신임 | 본체임 | 인물·신격·용종 | 방향 |
| 인물·아이템·용종 | 복제됨 | 원본임 | 인물·아이템·용종 | 방향 |
| 인물·단체·국가 | 개조함 | 개조됨 | 인물·아이템·용종 | 방향 |
| 사건·개념·아이템·지형·인물·신격·용종 | 변이 원인임 | 변이됨 | 인물·종족·용종·아이템 | 방향 |
| 인물·아이템·용종·개념 | 변형됨 | 원형임 | 인물·아이템·용종·개념 | 방향 |
| 아이템·개념·클래스·용종 | 파생됨 | 원형임 | 아이템·개념·클래스·용종 | 방향 |
| 인물·신격·용종 | 빙의함 | 빙의당함 | 인물·아이템·용종 | 방향 |
| 인물·신격·개념 | 현현함 | 현현 대상임 | 인물·아이템·지형·도시 | 방향 |
| 인물·아이템·용종 | 융합됨 | 융합 재료임 | 인물·아이템·용종 | 방향 |

### 설명

- `계승함`: 지위·사명·유산·권능·책임을 이어받음
- `후계자임`: 아직 승계가 완료되지 않은 후계 구도
- `권한을 승계함`: 특정 통치권·지휘권·관리권만 넘겨받음
- `칭호를 계승함`: 세습 명칭이나 지위를 이어받음
- `환생함`: 동일한 영혼이나 존재가 다른 생으로 다시 태어남
- `화신임`: 상위 존재·신격·개념이 특정 형상으로 나타남
- `분신임`: 본체의 일부나 파생 개체가 동시에 존재함
- `복제됨`: 인공적·마법적으로 원본을 복제함
- `개조함`: 의도적인 외부 개입으로 구조·기능을 변경함
- `변이 원인임`: 의도 여부와 무관하게 변이를 유발한 원인
- `변형됨`: 변형된 대상과 이전 원형을 직접 연결함
- `파생됨`: 원형을 바탕으로 별도 계통·유형이 생김
- `빙의함`: 다른 존재나 매개체 내부에 들어가 영향을 줌
- `현현함`: 신격·개념·권능이 현실에 드러남
- `융합됨`: 둘 이상의 대상이 하나의 결과물로 결합됨

### 예시

```text
왕자 → 후계자임 → 국왕
새로운 교단 → 계승함 → 멸망한 교단
인물 A → 환생함 → 인물 B
용종 A → 변형됨 → 원종 B
오염지대 → 변이 원인임 → 용종 C
연구 단체 → 개조함 → 전투 구조체
```

## 8. 등록 원칙

- 관계의 양 끝은 같은 월드의 등록 문서여야 한다.
- 관계 유형별 대상 1·대상 2 권장 카테고리를 기준으로 앱의 문서 목록을 필터링한다.
- 권장 조합을 벗어난 경우 초기에는 경고만 표시하고 등록은 허용한다.
- 대칭 관계는 하나의 레코드만 저장한다.
- 방향 관계는 정방향 관계명과 역관계 표시명을 함께 가진다.
- 기간, 역할, 상태, 원인, 종료 사유는 관계 레코드의 보조 속성으로 기록한다.
