# 프로젝트 위그드라실 범용 관계 유형 정리 — 소유·제작·운용 관계

> 상태: 브레인스토밍 확정본  
> 범위: 소유·점유, 사용·운용, 제작·설계, 이전·수여, 강제 취득·상실, 파괴·손상·변질 관계  
> 원칙: 관계의 주체와 대상은 모두 같은 월드의 `documents`에 등록된 문서만 허용한다.

## 1. 소유·점유 관계

| 대상 1 | 관계 | 역관계 | 대상 2 | 방향 |
| --- | --- | --- | --- | --- |
| 인물·단체·국가 | 소유함 | 소유됨 | 아이템·문서·장치·운송체·공간형 아이템 | 방향 |
| 인물·단체·국가 | 공동 소유함 | 공동 소유됨 | 아이템·문서·장치·운송체 | 방향 |
| 인물·단체·국가 | 점유함 | 점유됨 | 아이템·문서·장치·운송체·도시·지형 | 방향 |
| 인물·단체·국가 | 보관함 | 보관됨 | 아이템·문서·장치 | 방향 |
| 인물·단체·국가 | 소유권을 주장함 | 소유권 주장 대상임 | 아이템·문서·장치·운송체 | 방향 |
| 인물·단체·국가 | 임차함 | 임대됨 | 아이템·장치·운송체·도시·지형 | 방향 |
| 인물·단체·국가 | 강탈함 | 강탈당함 | 아이템·문서·장치·운송체 | 방향 |
| 인물·단체·국가 | 탈환함 | 탈환됨 | 아이템·문서·장치·운송체·도시·지형 | 방향 |

### 설명

- `소유함`: 법적·사회적·설정상 소유권을 가짐
- `공동 소유함`: 둘 이상의 주체가 같은 대상의 소유권을 함께 가짐
- `점유함`: 실제로 대상을 보유하거나 통제하고 있음
- `보관함`: 물리적 보존이나 보관 책임을 맡음
- `소유권을 주장함`: 소유권이 확정되지 않은 상태에서 권리를 주장함
- `임차함`: 일정 기간 사용권이나 점유권을 빌림
- `강탈함`: 폭력·위협·강제력으로 대상을 빼앗음
- `탈환함`: 빼앗기거나 점령된 대상을 강제로 되찾음

`강탈당함`은 일상적으로는 `빼앗김`과 같은 의미지만, 관계명은 정방향과의 대응을 위해 `강탈당함`으로 통일한다.

### 예시

```text
왕국 → 소유함 → 왕실 성검
도적단 → 점유함 → 왕실 성검
귀족 가문 A → 공동 소유함 → 선조의 유산
왕국 A → 소유권을 주장함 → 분쟁 중인 유물
상단 → 임차함 → 비공정
도적단 → 강탈함 → 왕실 성검
왕국군 → 탈환함 → 왕실 성검
```

## 2. 사용·운용 관계

| 대상 1 | 관계 | 역관계 | 대상 2 | 방향 |
| --- | --- | --- | --- | --- |
| 인물·단체·국가 | 사용함 | 사용됨 | 아이템·장치·시설 | 방향 |
| 인물·단체·국가 | 운용함 | 운용됨 | 장치·탈것·시설·체계 | 방향 |
| 인물·용종 | 장착함 | 장착됨 | 아이템·장치 | 방향 |
| 인물·종족·용종 | 탑승함 | 탑승 대상임 | 탈것·용종·장치 | 방향 |
| 인물·단체 | 조작함 | 조작됨 | 장치·아이템·시설 | 방향 |
| 인물·단체·국가 | 조종함 | 조종됨 | 탈것·장치·용종 | 방향 |
| 인물·단체·국가 | 가동함 | 가동됨 | 장치·시설·체계 | 방향 |
| 인물·단체·국가 | 활성화함 | 활성화됨 | 아이템·장치·시설·개념 | 방향 |
| 인물·단체·국가 | 배치함 | 배치됨 | 아이템·장치·시설·단체 | 방향 |
| 인물·단체·국가 | 설치함 | 설치됨 | 장치·아이템·시설 | 방향 |

### 설명

- `사용함`: 대상의 기능을 일반적으로 활용함
- `운용함`: 인력·절차·자원을 투입하여 지속적으로 운영함
- `장착함`: 신체나 외장 구조에 부착하여 사용함
- `탑승함`: 탈것·용종·장치에 올라 이동하거나 이용함
- `조작함`: 제어판·장치·기능을 직접 다룸
- `조종함`: 탈것·장치·탑승 생물의 이동과 방향을 제어함
- `가동함`: 정지된 장치·시설·체계를 작동 상태로 전환함
- `활성화함`: 잠든 기능·권능·마법 효과를 깨움
- `배치함`: 대상에 임무나 위치를 부여하여 놓음
- `설치함`: 장치·시설을 특정 장소에 고정하거나 구축함

구속·통제 관계의 `조종함 ↔ 조종당함`은 `통제함 ↔ 통제당함`으로 변경하여 구분한다.

### 예시

```text
마법사 → 사용함 → 마도서
상단 → 운용함 → 비공정
드로이드 → 장착함 → 우팔 캐논
기수 → 탑승함 → 비룡
기술자 → 조작함 → 방벽 제어판
조종사 → 조종함 → 비공정
마탑 → 가동함 → 방어 결계
성기사 → 활성화함 → 성검
왕국 → 배치함 → 이동식 포대
기술단 → 설치함 → 고정식 포대
```

## 3. 제작·설계 관계

| 대상 1 | 관계 | 역관계 | 대상 2 | 방향 |
| --- | --- | --- | --- | --- |
| 인물·단체·국가·신격 | 제작함 | 제작됨 | 아이템·장치 | 방향 |
| 인물·단체·국가 | 설계함 | 설계됨 | 아이템·장치·시설 | 방향 |
| 인물·단체·국가 | 발명함 | 발명됨 | 아이템·장치·기술·개념 | 방향 |
| 인물·단체·국가 | 개발함 | 개발됨 | 아이템·장치·기술·체계 | 방향 |
| 인물·단체·국가·신격 | 창조함 | 창조됨 | 인물·종족·용종·아이템·신격·지형 | 방향 |
| 인물·단체·국가 | 건조함 | 건조됨 | 탈것·함선·대형 장치·시설 | 방향 |
| 인물·단체·국가 | 구축함 | 구축됨 | 시설·체계·결계·기반 시설 | 방향 |
| 인물·단체·국가 | 복원함 | 복원됨 | 아이템·장치·시설·도시·문서 | 방향 |
| 인물·단체 | 수리함 | 수리됨 | 아이템·장치·시설 | 방향 |
| 인물·단체·국가 | 개량함 | 개량됨 | 아이템·장치·시설·기술 | 방향 |
| 인물·단체·국가·신격 | 강화함 | 강화됨 | 인물·아이템·장치·시설·용종 | 방향 |
| 인물·단체 | 재현함 | 재현됨 | 아이템·장치·기술·개념 | 방향 |
| 인물·단체 | 분해함 | 분해됨 | 아이템·장치 | 방향 |
| 인물·단체·국가 | 해체함 | 해체됨 | 아이템·장치·시설·탈것 | 방향 |
| 인물·단체·국가 | 철거함 | 철거됨 | 시설·건축물·고정 장치 | 방향 |

### 설명

- `제작함`: 개별 물건이나 장치를 실제로 만듦
- `설계함`: 구조·형태·작동 원리를 고안함
- `발명함`: 이전에 없던 원리·기술·장치를 최초로 고안함
- `개발함`: 기존 원리나 기술을 실용화하거나 발전시킴
- `창조함`: 생명·종족·신격·초월적 대상 등을 만들어냄
- `건조함`: 함선·비공정·대형 탈것·대형 구조물을 만듦
- `구축함`: 시설망·체계·결계·기반 구조를 마련함
- `복원함`: 손상·소실된 대상을 원형에 가깝게 되돌림
- `수리함`: 고장이나 손상을 고쳐 기능을 회복함
- `개량함`: 기존 용도를 유지하며 구조나 성능을 개선함
- `강화함`: 힘·내구·권능·효과를 증대함
- `재현함`: 과거의 물건·기술·현상을 다시 구현함
- `분해함`: 아이템이나 장치를 구성 부품 단위로 풀어냄
- `해체함`: 복합 장치·탈것·시설의 구조와 기능을 거둬들임
- `철거함`: 장소에 고정된 시설이나 건축물을 제거함

`제작함 ↔ 제작됨`과 `분해함 ↔ 분해됨`은 서로 다른 관계다. 분해는 제작의 역관계가 아니라 별도의 변화 행위로 본다.

### 예시

```text
대장장이 → 제작함 → 성검
기술자 → 설계함 → 비공정
연금술사 → 발명함 → 마력 축전기
제국 연구소 → 개발함 → 전투 드로이드
신격 → 창조함 → 종족
조선소 → 건조함 → 전함
왕국 → 구축함 → 역참 체계
고고학자 → 복원함 → 고대 문서
기술자 → 수리함 → 드로이드
기술단 → 개량함 → 전투 장치
마법사 → 강화함 → 성검
연구소 → 재현함 → 고대 병기
기술자 → 분해함 → 고대 장치
조선소 → 해체함 → 노후 전함
도시 행정부 → 철거함 → 폐쇄된 감시탑
```

## 4. 이전·수여 관계

| 대상 1 | 관계 | 역관계 | 대상 2 | 방향 |
| --- | --- | --- | --- | --- |
| 인물·단체·국가·신격 | 수여함 | 수여받음 | 인물·단체·국가 | 방향 |
| 인물·단체·국가·신격 | 증여함 | 증여받음 | 인물·단체·국가 | 방향 |
| 인물·단체·국가 | 헌정함 | 헌정받음 | 인물·단체·국가·신격 | 방향 |
| 인물·단체·국가 | 상속함 | 상속받음 | 인물·단체·국가 | 방향 |
| 인물·단체·국가 | 양도함 | 양도받음 | 인물·단체·국가 | 방향 |
| 인물·단체·국가 | 대여함 | 대여받음 | 인물·단체·국가 | 방향 |
| 인물·단체·국가 | 반환함 | 반환받음 | 인물·단체·국가 | 방향 |
| 인물·단체·국가 | 매각함 | 매입함 | 인물·단체·국가 | 방향 |
| 인물·단체·국가 | 배분함 | 배분받음 | 인물·단체·국가 | 방향 |

### 설명

- `수여함`: 권위 있는 주체가 물건·지위·권한·칭호를 공식적으로 내림
- `증여함`: 대가 없이 재산이나 소유권을 넘김
- `헌정함`: 존경·신앙·기념의 의미로 작품이나 대상을 바침
- `상속함`: 사망·퇴임·가문 규칙 등에 따라 재산·권리·지위를 넘김
- `양도함`: 소유권·권리·지위·채권 등을 일반적으로 넘김
- `대여함`: 소유권을 유지한 채 일정 기간 사용권을 넘김
- `반환함`: 빌리거나 점유하던 대상을 원래 주체에게 돌려줌
- `매각함`: 대가를 받고 소유권을 넘김
- `배분함`: 공동 재산·전리품·자원·권한을 여러 주체에게 나눔

`하사함`은 `수여함`, `양여함`은 `증여함` 또는 `양도함`, `교환함`은 양방향 `양도함`으로 처리한다.

### 예시

```text
국왕 → 수여함 → 기사
가문주 → 증여함 → 자녀
장인 → 헌정함 → 신격
선대 가주 → 상속함 → 후계자
상단 A → 양도함 → 상단 B
왕국 → 대여함 → 탐사 연맹
탐사대 → 반환함 → 왕국
상단 A → 매각함 → 상단 B
기사단 → 배분함 → 소속 기사
```

## 5. 강제 취득·상실 관계

| 대상 1 | 관계 | 역관계 | 대상 2 | 방향 |
| --- | --- | --- | --- | --- |
| 인물·단체·국가 | 압수함 | 압수됨 | 아이템·문서·장치 | 방향 |
| 인물·단체·국가 | 몰수함 | 몰수됨 | 아이템·문서·장치·재산 | 방향 |
| 인물·단체 | 훔침 | 도난당함 | 아이템·문서·장치 | 방향 |
| 인물·단체·국가 | 회수함 | 회수됨 | 아이템·문서·장치 | 방향 |
| 인물·단체·국가 | 압류함 | 압류됨 | 아이템·문서·장치·재산 | 방향 |
| 인물·단체·국가 | 징발함 | 징발됨 | 아이템·장치·시설·탈것 | 방향 |
| 인물·단체·국가 | 분실함 | 분실됨 | 아이템·문서·장치 | 방향 |
| 인물·단체·국가 | 폐기함 | 폐기됨 | 아이템·문서·장치 | 방향 |
| 인물·단체·국가 | 은닉함 | 은닉됨 | 아이템·문서·장치 | 방향 |

### 설명

- `압수함`: 법적·행정적 권한으로 대상을 일시적으로 확보함
- `몰수함`: 처벌에 따라 소유권 자체를 박탈함
- `훔침`: 은밀하거나 불법적으로 타인의 대상을 취득함
- `회수함`: 원래 소유권·관리권·임무상 권한이 있는 대상을 다시 확보함
- `압류함`: 채무·판결·법 집행에 따라 처분권이나 사용권을 제한함
- `징발함`: 국가나 군사 조직이 민간 재산이나 자원을 강제로 사용함
- `분실함`: 대상의 위치나 통제권을 잃음
- `폐기함`: 사용·보존 가치가 없거나 위험하다고 판단해 처분함
- `은닉함`: 다른 주체가 찾거나 접근하지 못하도록 숨김

`탈취함`은 `강탈함`으로 통합하고, `압류 해제함`은 관계 종료 기록으로 관리한다.

### 예시

```text

왕국 → 몰수함 → 반역 귀족의 재산
도적 → 훔침 → 왕실 보석
기사단 → 회수함 → 도난당한 성물
채권자 단체 → 압류함 → 채무자의 비공정
왕국군 → 징발함 → 상단의 마차
기사 → 분실함 → 가문의 인장
연구소 → 폐기함 → 실패한 시제품
교단 → 은닉함 → 성물
```

### 설명

- `파괴함`: 회복하기 어려울 정도로 전체 형태나 기능을 무너뜨림
- `훼손함`: 일부 형태·가치·기능을 손상함
- `소실시킴`: 대상을 완전히 사라지게 하거나 존재 여부를 불명확하게 만듦
- `오염시킴`: 외부 물질·에너지·성질이 섞여 정상 상태를 해침
- `부식시킴`: 재질이나 구조를 점진적으로 약화시킴
- `저주함`: 초자연적 조건·불이익·효과를 부여함
- `변질시킴`: 대상의 본래 성질을 다른 상태로 바꿈
- `정화함`: 오염·저주·침식·부정적 성질을 제거함
- `봉인 해제함`: 봉인의 효력과 구속을 제거함
- `무력화함`: 대상을 파괴하지 않고 기능·위협·권능을 사용하지 못하게 함
- `침식함`: 영역·정신·생명력·권능을 점진적으로 잠식함
- `붕괴시킴`: 대형 구조나 체계를 연쇄적으로 무너뜨림

`손상시킴`은 `훼손함`, `복구함`은 `수리함·복원함·구축함·정화함`으로 통합한다. `소각함`은 `파괴함`의 방식 속성으로 기록한다.

```text

앙그라의 안개 → 침식함 → 숲

```

## 9. 등록 원칙

- 관계의 양 끝은 모두 같은 월드의 등록 문서여야 한다.
- 앱에서는 관계 유형별 대상 1·대상 2 권장 카테고리를 기준으로 문서 목록을 필터링한다.
- 판타지 세계관의 예외를 막지 않도록 권장 조합을 벗어나도 초기에는 경고만 표시한다.
- 방향 관계는 정방향 관계명과 역관계 표시명을 함께 가진다.
- 관계의 성립 시점, 종료 시점, 현재 상태, 원인, 방식, 목적, 조건은 보조 속성으로 기록한다.
- `소유함`, `점유함`, `보관함`, `운용함`은 같은 대상에 동시에 성립할 수 있다.
- `제작함`, `설계함`, `발명함`, `개발함`은 서로 다른 주체에게 동시에 연결될 수 있다.
- 일시적인 사용·조작·파손까지 모두 관계로 등록하지 않고, 설정상 지속성이나 역사적 중요성이 있는 경우만 등록한다.
- 실제 거래 대상, 수여 물품, 계약 조건처럼 세 번째 문서가 필요한 정보는 별도 관계나 보조 속성으로 기록한다.
- 상태 변경을 되돌리는 행위는 관계 삭제로 처리하지 않는다. 기존 관계의 종료 시점과 새로운 행위 관계를 함께 기록한다.
