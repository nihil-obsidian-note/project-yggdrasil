# 범용 관계 문장 결합 템플릿 카탈로그

> 상태: 관계 정리본 2.1~2.5 전면 개편 공통 기준  
> 대상 수: 최소 2개, 최대 4개  
> 핵심: `{관계}`는 고정 문구가 아니라 사용자가 선택한 정방향·역방향 관계명 변수다.

## 1. 운용 원칙

- 실제 관계를 등록할 때 사용자가 허용 템플릿 중 하나를 고른다.
- 관계 유형은 정방향 관계명과 역방향 관계명을 변수로 제공한다.
- 대상 슬롯에는 관계 역할에 연결된 문서가 들어간다.
- 문서명 받침에 따라 `이/가`, `을/를`, `과/와`, `으로/로`를 자동 변환한다.
- 괄호 속 대상도 정식 관계 참여자이며 별도 메타데이터가 아니다.
- 5개 이상의 대상은 허용하지 않는다.

## 2. 조사 토큰

| 토큰 | 출력 규칙 |
| --- | --- |
| `{이/가}` | 받침 있음 `이`, 없음 `가` |
| `{은/는}` | 받침 있음 `은`, 없음 `는` |
| `{을/를}` | 받침 있음 `을`, 없음 `를` |
| `{과/와}` | 받침 있음 `과`, 없음 `와` |
| `{으로/로}` | 받침 있음 `으로`, 없음 `로`; 받침 `ㄹ`은 `로` |
| `{에}` | 고정 조사 |
| `{에게}` | 고정 조사 |
| `{에서}` | 고정 조사 |
| `{에게서}` | 고정 조사 |
| `{으로부터/로부터}` | 받침 규칙 적용 |

## 4. 문서별 표시 규칙

현재 열람 중인 문서는 템플릿에서 생략할 수 있다. 나머지 슬롯과 해당 방향의 관계명을 유지하여 표시한다.

예시 관계: 선포 주체=`에리디안 제국`, 선포 대상=`발가르 왕국`, 관련 전쟁=`그림자 전쟁`

```text
전체 확인: 에리디안 제국이 발가르 왕국에 선전포고함 (그림자 전쟁)
에리디안 제국 문서: 발가르 왕국에 선전포고함 (그림자 전쟁)
발가르 왕국 문서: 에리디안 제국에 선전포고당함 (그림자 전쟁)
그림자 전쟁 문서: 에리디안 제국이 발가르 왕국에 선전포고함
```

## 5. 템플릿 선택 검증

- 선택한 템플릿의 대상 수와 실제 참여자 수가 일치해야 한다.
- 모든 필수 역할이 슬롯에 매핑되어야 한다.
- 같은 역할이 둘 이상의 슬롯에 중복 배치되어서는 안 된다.
- 관계명이 들어간 뒤 실제 한국어 문장으로 자연스러운지 미리보기에서 확인한다.
- 사용자가 템플릿을 바꾸어도 관계 참여자와 역할 레코드는 유지한다.
