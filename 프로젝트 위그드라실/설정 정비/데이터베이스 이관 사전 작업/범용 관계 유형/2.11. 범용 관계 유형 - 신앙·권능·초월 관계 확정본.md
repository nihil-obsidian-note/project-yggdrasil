# 프로젝트 위그드라실 범용 관계 유형 정리 — 신앙·권능·초월 관계

> 상태: 최종 확정본  
> 범위: 신앙·숭배, 기도·제의·봉헌, 계시·신탁·선택, 가호·축복·신벌, 권능 부여·회수·관장, 신격 상태, 강림·성역·신성  
> 적용 범위: `COMMON`  
> 원칙: 관계 인스턴스는 2~4개의 문서 참여 대상을 가지며, 각 대상 역할에는 허용 문서 카테고리를 명시한다.

## 1. 범위와 기본 원칙

2.11은 존재와 공동체가 초월적 대상을 믿고 숭배하는 관계, 종교적 행위, 초월적 의사의 전달, 신성한 보호와 처벌, 권능과 신격의 변화, 강림과 성역의 형성을 정의한다.

- 신앙·숭배는 초월적 대상에 대한 지속적인 믿음과 경배를 표현한다.
- 기도·제의·봉헌은 신앙을 실제 행위로 표현한 관계다.
- 계시·신탁·선택은 초월적 주체가 의사·정보·역할을 전달하는 관계다.
- 가호·축복·신벌은 초월적 권위가 대상에게 보호·은총·처벌을 적용하는 관계다.
- 권능은 일반 능력과 구분되는 신격·초월적 존재의 힘으로 취급한다.
- 신격의 획득·향상·하락·상실·박탈·회복은 서로 다른 상태 변화로 분리한다.
- 강림은 현현과 구분하며, 성역 지정과 실제 성역화도 별도 관계로 관리한다.
- 관계 대상은 최소 2개, 최대 4개다.
- 자연스러운 역방향 표시명이 없는 관계는 역방향을 만들지 않는다.
- 이 문서의 기본 대상 카테고리는 범용 11개인 개념·신격·국가·도시·단체·종족·인물·아이템·사건·설화·지형이다.
- 룩스테라 `용종`과 엘드로스 `클래스`는 별도 세계별 확장 매핑에서만 추가한다.

### 의미 경계

- `신앙함`은 믿음과 교리 수용을 중심으로 한다.
- `숭배함`은 경배와 예배 행위를 중심으로 하며 신앙과 동시에 성립할 수 있다.
- `신성시함`은 대상을 성스럽다고 인식하는 관계이며 반드시 신앙하거나 숭배한다는 뜻은 아니다.
- `개종함`은 당사자의 신앙 변화이고, `개종시킴`은 변화를 일으킨 외부 주체가 존재하는 관계다.
- `배교함`은 기존 신앙을 떠나는 행위이며 새로운 신앙으로 이동하지 않아도 성립한다.

### 의미 경계

- `봉헌함`은 대상에게 물건·장소·성과 등을 헌정하는 행위다.
- `제물을 바침`은 제의의 대가나 희생물로 대상을 제공하는 행위다.
- `순례함`은 신앙적 목적을 가진 이동이며 일반 여행·방문과 구분한다.

### 의미 경계와 기존 관계 재사용

- `계시함`은 초월적 진실·의지·지식을 드러내는 관계다.
- `신탁을 내림`은 질문·의식·예언적 판단에 대한 공식적인 초월적 응답이다.
- `선택함`은 사명·역할·운명을 맡길 대상을 지정하는 관계다.
- `사도로 임명함 ↔ 사도로 임명됨`은 신규 relation type으로 만들지 않는다.
- 사도 임명은 기존 범용 `임명함`에서 `임명 역할=사도`로 등록한다.

### 의미 경계와 재분류

- `가호함`은 대상에 대한 지속적인 보호·후원 상태다.
- `축복함`은 구체적인 은총·효과·조건을 부여하는 행위다.
- `신벌을 내림`은 신성한 권위에 근거한 처벌이며 일반 저주와 구분한다.
- `파문함`은 종교 공동체의 소속·성직·성사 자격을 박탈하는 관계다.
- `속죄를 인정함`은 죄를 씻기 위한 행위나 조건이 종교적으로 충족되었다고 판정하는 관계다.
- `파문함 ↔ 파문당함`은 기존 2.2 relation type을 신규 생성하지 않고 2.11-4로 재분류한다.

- 물리적 차지와 통치는 각각 기존 `점유함`, `지배함`을 재사용한다.

### 룩스테라

룩스테라 전용 신규 relation type은 추가하지 않는다. 정령성·신앙·용성·신위·디바인은 범용 관계의 대상 또는 세계별 표시명으로 적용한다.

| 디바인을 거두어들임 | 권능을 회수함 |
| 디바인을 강제로 제거함 | 권능을 박탈함 |

`정령으로 상승함`, `용성을 축적함`, `천룡으로 승천함` 같은 세계 고유 성장 과정은 관계명으로 만들지 않고 설정·사건·종족·신격 상태 데이터로 기록한다.

### 엘드로스

엘드로스 클래스 관계는 신앙·권능·초월 관계에 포함하지 않는다. 클래스 관계 7개는 별도 `엘드로스 클래스 전용 관계 추가 확정본.md`에서 기존 2.2·2.4의 `SERIES` 확장으로 관리한다.

## 5. 관계 수 집계

| 세부 파트 | 확정 relation type |
| --- | ---: |
| 2.11-1 신앙·숭배 | 6 |
| 2.11-2 기도·제의·봉헌 | 5 |
| 2.11-3 계시·신탁·선택 | 3 |
| 2.11-4 가호·축복·신벌 | 5 |
| 2.11-5 권능 부여·회수·관장 | 5 |
| 2.11-6 신격 상태 | 6 |
| 2.11-7 강림·성역·신성 | 4 |
| **합계** | **34** |

34개 가운데 `파문함 ↔ 파문당함` 1개는 기존 2.2 relation type을 재분류한 것이다. 따라서 2.11 확정으로 새로 추가되는 `COMMON` relation type은 33개다.

2.1~2.10 활성 relation type 752개에 2.11 구성 관계 34개를 더한 누적 고유 `COMMON` relation type은 총 **786개**다. 이는 2.10까지 확정된 고유 753개 가운데 `파문함 ↔ 파문당함` 1개를 2.11로 옮기고 신규 33개를 추가한 결과다.

## 6. 최종 판정

2.11 신앙·권능·초월 관계는 총 34개 relation type으로 최종 확정한다.

- 자체 구성 관계: 34개
- 기존 관계 재분류: 1개
- 실제 신규 관계: 33개
- 룩스테라 전용 신규 관계: 0개
- 엘드로스 클래스 관계: 별도 `SERIES` 확정본으로 분리
- 2.11로 이관되었으나 미처리된 관계: 없음
