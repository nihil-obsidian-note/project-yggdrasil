# 2.5.1 괄호형 관계 분리 확정 갱신본

> 상태: 확정본  
> 범위: 2.1~2.5 관계 중 세부 의미를 사용자 선택형 독립 relation type으로 분리한 관계  
> 원칙: 괄호형 관계명은 표시용 별칭이 아니라 데이터베이스에 별도 ID로 등록되는 독립 관계 유형이다.

## 1. 범위와 기본 원칙

이 문서는 2.1~2.5 관계 검토 이후 추가로 확정한 괄호형 관계 유형만 정의한다. 기존 상위 관계의 존재 여부나 변경 이력은 다루지 않으며, 아래 각 항목을 독립된 관계 유형으로 직접 등록한다.

- 괄호 안의 세부 유형은 자유 입력 값이나 보조 속성이 아니라 관계명 자체의 일부다.
- 같은 기본 관계에서 파생되더라도 각 괄호형 관계는 서로 다른 relation type ID를 가진다.
- 사용자는 관계 생성 시 일반 관계와 괄호형 세부 관계 가운데 필요한 유형을 직접 선택한다.
- 방향 관계는 정방향과 역방향 표시명을 함께 정의한다.
- 대칭 관계는 별도 역방향 이름을 두지 않고 동일 관계 유형을 양쪽에서 사용한다.
- 관계 참여 대상은 2개 이상 4개 이하로 제한한다.
- 대상 역할은 관계마다 명시하며, 선택 역할은 `(선택)`으로 표시한다.
- 템플릿의 대상 치환자는 숫자 슬롯이 아니라 의미 역할명을 사용한다.
