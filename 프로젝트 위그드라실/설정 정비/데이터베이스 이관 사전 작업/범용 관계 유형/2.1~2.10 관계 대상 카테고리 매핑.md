# 2.1~2.10 관계 대상 카테고리 매핑

> 상태: 범용 기준 확정 매핑  
> 범위: 2.1~2.10 활성 relation type 752개와 2.5.1 괄호형 독립 relation type을 포함한 모든 대상 역할  
> 범용 기준 카테고리: 개념, 신격, 국가, 도시, 단체, 종족, 인물, 아이템, 사건, 설화, 지형

## 1. 목적

이 문서는 관계 유형마다 대상 역할이 어떤 문서 카테고리를 받을 수 있는지 명시한다. 관계의 대상 수가 2~4개로 달라져도 각 슬롯은 숫자가 아니라 의미 역할과 허용 카테고리 집합으로 판정한다.

기존 확정본의 `권장 문서` 표기는 현재 11개 범용 카테고리로 정규화했다. 권장 문서가 없었던 역할은 관계 의미와 대상 역할을 분석해 허용 카테고리를 판정했다.

## 2. 적용 원칙

- 카테고리 표기는 메인 카테고리 ID 기준이다. 하위 카테고리 문서는 해당 메인 카테고리 허용 범위에 포함된다.
- 하나의 역할에 카테고리 하나만 적힌 경우 해당 카테고리만 허용한다.
- 여러 카테고리가 적힌 경우 그 목록 가운데 하나를 선택한다.
- `전체 11개`는 역할 자체가 범용 대상·비교 대상·관련 대상이어서 특정 카테고리로 제한하면 설정 사실을 손실하는 경우에만 사용한다.
- 선택 역할도 값이 입력되는 순간 동일한 카테고리 검증을 적용한다.
- 2.5.1은 2.1~2.5에서 파생된 별도 relation type이므로 전체 매핑 범위에 포함한다.
- 이 문서는 2.1~2.10 관계 유형별 대상 카테고리 정본으로 사용한다. 2.11은 `2.11 관계 대상 카테고리 매핑.md`를 추가 적용한다.
- 전역 번호는 기존 데이터 참조 안정성을 위해 재번호하지 않는다. 2.11로 재분류된 `55`는 이 문서에서 폐기·예약 번호로 남기고 새 관계에 재사용하지 않는다.

### 세계별 확장 카테고리

| 구분 | 카테고리 | 적용 기준 |
| --- | --- | --- |
| 범용 | 개념·신격·국가·도시·단체·종족·인물·아이템·사건·설화·지형 | 모든 세계와 모든 범용 관계에 기본 적용 |
| 룩스테라 확장 | 용종 | 룩스테라에만 존재하는 세계 전용 카테고리 |
| 엘드로스 확장 | 클래스 | 엘드로스에만 존재하는 세계 전용 카테고리 |

- 모든 범용 관계의 기본 대상 카테고리 매핑은 범용 11개만 사용한다.
- `용종`과 `클래스`는 범용 전체 허용에 자동 포함하지 않는다.
- 세계별 확장 카테고리를 관계에 허용하려면 해당 세계의 관계 적용 범위를 별도로 검토해 명시적으로 추가한다.
- 이 정본의 관계별 매핑 표에는 세계별 확장 카테고리를 포함하지 않는다.

## 6. DB·UI 적용 기준

관계 유형과 대상 역할 사이에는 허용 카테고리 다대다 매핑을 둔다. 관계 생성 화면은 선택된 relation type과 역할에 연결된 카테고리만 문서 검색 후보로 노출한다.

`전체 11개` 역할도 구현상 예외 문자열로 저장하지 않고 11개 카테고리 매핑 레코드로 전개한다. 카테고리가 추가되더라도 기존 전체 허용 역할에 자동 포함하지 않으며, 관계 의미를 다시 검토한 뒤 명시적으로 추가한다.

카테고리 불일치는 저장 전에 차단하는 것을 기본으로 한다. 기존 데이터 이관 중 불일치가 발견되면 강제로 통과시키지 않고 카테고리 오분류, 역할 매핑 누락, 관계 유형 선택 오류 가운데 원인을 판정한다.
