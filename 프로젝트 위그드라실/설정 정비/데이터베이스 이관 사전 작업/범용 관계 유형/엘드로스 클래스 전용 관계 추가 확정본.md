# 엘드로스 클래스 전용 관계 추가 확정본

> 상태: 최종 확정본  
> 적용 세계: 엘드로스  
> 적용 범위: `SERIES`  
> 기준 정본: `2.1~2.10 관계 대상 카테고리 매핑.md`, `2.11 관계 대상 카테고리 매핑.md`, `엘드로스 클래스 관계 대상 확장 매핑.md`  
> 원칙: 클래스 전용 관계는 범용 relation type 수량에 포함하지 않고, 기존 2.2·2.4의 의미 파트에 귀속되는 세계별 확장으로 관리한다.

## 1. 목적

이 문서는 기존 범용 관계로 정확하게 표현할 수 없는 엘드로스 클래스 체계의 보유, 각성, 부여, 박탈, 상실, 전직, 사용 자격 관계를 확정한다.

클래스는 일반 직업이나 외부 기관이 발급하는 자격이 아니다. 위그드라실 시스템이 개인의 능력·자질·경험·성향·잠재력을 분류하고 스킬과 성장 계통으로 정형화한 결과다.

- 클래스는 시스템에게서만 부여받을 수 있다.
- `클래스를 가짐`은 현재 상태이고, `클래스를 부여받음`은 획득 사건이다.
- 최초로 헌터가 되는 능력 발현은 각성이다.
- 상위 단계의 변화는 각성과 전직이 함께 성립할 수 있다.
- 클래스 박탈·상실은 직위나 자격 박탈이 아니라 해당 능력 자체의 제거다.
- 다중 클래스 보유자는 특정 클래스만 박탈·상실할 수 있다.
- 클래스가 실제로 대상을 사용하는 행위와 사용할 수 있는 자격을 구분한다.
- 관계 대상은 최소 2개, 최대 4개다.
- 자연스러운 역방향 표시명이 없는 관계는 역방향을 만들지 않는다.

## 4. 관계별 확정 기준

### 4.1 클래스를 가짐 ↔ 보유 클래스임

인물이 현재 특정 클래스를 보유한 상태를 나타낸다. 부여·각성·전직 사건이 끝난 뒤에도 지속되는 상태 관계다.

기존 `소속됨 ↔ 소속 인물`은 호환 슬롯으로 사용할 수 있으나, 인물이 클래스라는 조직에 소속된 것처럼 표시되는 문제가 있다. 정확한 표시와 조회를 위해 전용 relation type으로 확정한다.

### 4.2 클래스로 각성함 ↔ 각성 클래스임

능력이 최초로 발현되거나 상위 단계로 재각성하면서 특정 클래스가 나타나는 관계다.

- 최초 각성: `각성자 / 각성 클래스`를 필수 대상으로 사용한다.
- 상위 각성: 필요하면 `기존 클래스·단계`를 추가한다.
- 각성과 전직이 함께 일어난 경우 두 relation type을 같은 사건에 연결한다.
- 단순 `각성함`이 아니라 관계 대상을 분명히 하는 `클래스로 각성함`을 사용한다.

### 4.3 클래스를 부여함 ↔ 클래스를 부여받음

위그드라실 시스템이 개인에게 클래스와 그에 따른 능력 체계를 제공하는 사건이다.

- 부여 주체는 반드시 `시스템`이다.
- 국가·길드·단체·인물은 클래스를 추천하거나 훈련할 수 있지만 직접 부여할 수 없다.
- 범용 `수여함`은 물건·지위·권한·칭호의 공식 전달이므로 능력 자체를 발생시키는 클래스 부여를 대체하지 않는다.

### 4.4 클래스를 박탈함 ↔ 클래스를 박탈당함

외부 주체가 대상의 클래스 능력을 강제로 제거하는 관계다. 이를 실행한 주체가 반드시 존재한다.

클래스가 일시적으로 봉인·무력화되었을 뿐 능력 자체가 남아 있다면 박탈로 등록하지 않는다. 해당 경우에는 기존 `봉인함`, `무력화함` 관계를 사용한다.

### 4.5 클래스를 상실함

원인을 불문하고 보유하던 클래스 능력을 잃는 상태 변화다. 자연스러운 역방향 표시명이 없으므로 역방향을 만들지 않는다.

- 강제 박탈이 원인이면 `클래스를 박탈함`과 `클래스를 상실함`을 함께 등록한다.
- 부상·저주·능력 붕괴·사건 등 행위자가 없는 원인이면 `클래스를 상실함`만 등록한다.
- 다중 클래스 보유자는 상실한 클래스마다 별도 관계 인스턴스를 등록한다.
- 모든 클래스를 상실했는지는 활성 `클래스를 가짐` 관계가 남아 있는지로 판단한다.

### 4.6 전직함

기존 클래스를 기반으로 새로운 단계나 계통의 클래스로 변화한 관계다. 기반 클래스와 새로운 클래스의 역할이 다르므로 단일 역방향 표시명을 만들지 않는다.

- 최초 헌터화에는 `전직함`을 사용하지 않고 `클래스로 각성함`을 사용한다.
- 2차·3차 전직에는 `클래스로 각성함`과 `전직함`이 함께 성립할 수 있다.
- 전직은 기존 클래스의 자동 종료를 의미하지 않는다.
- 다중 클래스 체계에서는 기반 클래스가 유지된 채 새로운 클래스가 추가될 수 있다.

### 4.7 사용할 수 있음 ↔ 사용 가능 클래스임

특정 클래스가 아이템·장비·기술·장치를 사용할 자격을 가진 관계다.

범용 `사용함 ↔ 사용됨`은 실제 사용 행위이고, `사용할 수 있음`은 현재 사용하지 않더라도 성립하는 사용 자격이다. 두 관계는 동시에 존재할 수 있다.

## 5. 동시 등록 규칙

| 상황 | 등록 관계 |
| --- | --- |
| 최초로 능력이 발현되고 클래스가 생김 | 클래스로 각성함 + 클래스를 부여함 + 클래스를 가짐 |
| 상위 단계로 각성하고 새로운 클래스로 전직함 | 클래스로 각성함 + 전직함 + 클래스를 부여함 + 클래스를 가짐 |
| 기존 클래스를 유지한 채 추가 클래스를 얻음 | 클래스로 각성함 + 클래스를 부여함 + 클래스를 가짐 |
| 외부 주체가 클래스 능력을 제거함 | 클래스를 박탈함 + 클래스를 상실함 + 기존 클래스를 가짐 관계 종료 |
| 사건·부상·저주로 클래스 능력을 잃음 | 클래스를 상실함 + 기존 클래스를 가짐 관계 종료 |
| 특정 클래스가 장비를 사용할 자격이 있음 | 사용할 수 있음 |
| 클래스 보유자가 실제로 장비를 사용함 | 기존 범용 사용함 |

`클래스를 가짐` 관계는 과거 기록을 삭제하지 않는다. 상실·박탈·전직으로 보유 상태가 종료되면 관계 인스턴스의 종료 시점이나 비활성 상태를 기록한다.

## 9. 최종 판정

엘드로스 클래스 전용 관계는 총 7개 `SERIES` relation type으로 최종 확정한다.

1. `클래스를 가짐 ↔ 보유 클래스임`
2. `클래스로 각성함 ↔ 각성 클래스임`
3. `클래스를 부여함 ↔ 클래스를 부여받음`
4. `클래스를 박탈함 ↔ 클래스를 박탈당함`
5. `클래스를 상실함`
