# 프로젝트 위그드라실 카테고리 이관 정리

> 상태: 카테고리 이관 데이터 v1 확정. DB 시드의 월드별 순서·경로·수량은 `../검토 및 추적/카테고리 이관 데이터 v1 최종 검토 및 동결.md`를 우선한다.

## 1. 적용 범위

이번 이관 대상은 `설정`, `신격`, `비밀 설정` 문서다. 세 문서군은 모두 단일 `documents` 모델로 이관한다. `docType`은 사용하지 않는다.

- 비밀 설정은 문서 유형이나 카테고리가 아니라 문서의 공개 범위 컬럼으로 제어한다.
- `스토리 설계`, `설정 정비`, 템플릿, 지침, 라이브러리, 인덱스는 이번 이관 대상이 아니다.
- `importance`는 문서 자체의 중요도이므로 `documents`의 컬럼으로 관리한다.

## 2. 카테고리 운영 원칙

1. 카테고리는 월드별 독립 데이터다. 모든 카테고리는 `world_id`에 소속된다.
2. 하위 카테고리 전용 테이블은 만들지 않는다. 하나의 `categories` 테이블에서 `upperCategoryId`로 계층을 표현한다. 계층은 메인·서브 1·서브 2의 최대 3단계다.
3. 문서 하나는 하나의 카테고리만 선택한다. 복수 성격, 상태, 속성, 위계는 태그와 문서 관계로 처리한다.
4. `일반`, 빈값, `기타`는 카테고리로 만들지 않는다. 해당 메인 카테고리에 직접 연결한다.
5. 초기 목록은 이관용 기준이며, 월드별 필요에 따라 카테고리를 추가할 수 있다.

## 4. 카테고리와 태그의 구분

| 대상 | 카테고리 처리 | 태그 처리 |
| --- | --- | --- |
| 신격 | 정령성 신위, 용성 신위 | 초신·대신·중신·소신·반신, 성향, 주신 여부 |
| 인물 | 주요 인물, 보조인물, 엑스트라, 단역 | 헌터, 클래스명 등 복수 역할 |
| 사건 | 사건의 본질적 성격 1개 | 범위, 시대, 관련 세력·장소 |
| 설화 | 민담, 소문, 전승, 신화 | 이본, 판본 상태 |
| 용종 | 기본 생물 계통 1개 | 고룡종, 재해룡종, 원종·아종·변종, 용성 속성 |

## 5. 기존 메타데이터 이관 규칙

1. 기존 `주요 개념` 문서는 `개념 > 주요`로 이관한다.
2. 기존 `주요`는 문서의 중요도를 뜻할 때 `importance` 컬럼으로 이관한다. 인물의 `주요 인물`은 문서 중요도와 별개인 배역 분류다.
3. 기존 `일반` 또는 빈 `subtype`은 해당 메인 카테고리에 직접 이관한다.
4. 기존 `도시국가`는 `도시 > 국가`로, 기존 `도시국가 / 항구`는 `도시 > 항구`로 이관한다.
5. 기존 `부족국가`는 `단체 > 부족국가`로 이관한다.
6. `용종` 개념 문서는 `개념` 카테고리에 두고, 개별 용종 도감 문서는 `용종` 카테고리와 해당 계통에 배정한다.
7. 현재 일반 신격은 `신격 > 정령성 신위`로, 흑린망룡은 `신격 > 용성 신위`로 이관한다.

## 6. 다음 논의 범위

다음 단계에서는 문서 간 관계 종류를 정리한다. 관계는 단순 참조가 아니라 소속, 출신, 포함, 소유, 전승 등 의미와 방향을 가진 연결로 설계한다.
