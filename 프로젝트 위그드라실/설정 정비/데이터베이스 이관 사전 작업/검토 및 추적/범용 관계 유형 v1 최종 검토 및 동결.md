## 판정

범용 관계 유형 v1을 확정·동결한다. 전역 ID 1~936은 연속하며, 대상 역할은 2,813개다. 아래 관계명 8쌍과 역할명 8쌍의 명명 정정을 이 문서의 DB 시드용 최종 기준으로 적용한다.

이 문서는 기존 파트별 확정본과 대상 카테고리 매핑의 내용을 재서술하거나 대체하지 않는다. 다만 DB 시드 생성에서는 이 문서의 `## 4`와 `## 5`를 해당 원천의 최종 오버레이로 우선 적용한다.

## 3. 동결 적용 규칙

1. 관계는 전역 ID를 변경하거나 재사용하지 않는다.
2. 괄호형 명칭은 보조 설명이 아니라 독립 `relationshipTypes` 행의 정식 이름이다.
3. `relationshipTypeRoles.name`은 관계 유형 안에서 유일해야 한다. 표시명도 같은 이름을 사용하되, DB 시드에는 역할 순서와 필수 여부를 함께 기록한다.
4. 역할별 허용 카테고리는 메인 카테고리 기준이다. 하위 카테고리 문서는 그 메인 카테고리 허용에 포함된다.
5. COMMON 관계는 월드별 `worldRelationshipTypes`와 `worldRelationshipRoleCategories`로 실체화한다. `scopeType`과 `seriesCode`는 원천 해석 규칙이며, 초기 테이블 명세의 최종 저장 열은 아니다.
6. 시드 입력은 이 문서의 원천 해시와 관계·역할 수량이 모두 일치할 때만 생성한다.

## 6. 초기 DB 시드의 확정 순서

1. `projects`에 `프로젝트 위그드라실`을 생성한다.
2. 같은 프로젝트 아래 `worlds`에 `룩스테라`, `엘드로스`를 생성한다.
3. 각 월드의 `categories`에 메인 카테고리를 먼저 생성하고, 그 ID로 하위 카테고리를 생성한다.
4. `relationshipTypes`에 COMMON 936개와 별도 SERIES 관계를 등록한다.
5. `relationshipTypeRoles`에 전역 ID별 역할·순서·필수 여부를 등록한다.
6. 각 월드에서 사용할 관계를 `worldRelationshipTypes`에 활성화한다.
7. 각 월드의 실제 카테고리 ID로 `worldRelationshipRoleCategories`를 생성한다.

룩스테라는 범용 97개와 용종 17개를 합친 114개 카테고리, 엘드로스는 범용 97개와 클래스 3개를 합친 100개 카테고리를 초기 생성 기준으로 사용한다.
