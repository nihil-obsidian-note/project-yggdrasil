# 데이터베이스 이관 사전 작업

이 폴더는 프로젝트 위그드라실 설정 문서의 데이터베이스 이관을 준비하기 위한 카테고리, 범용 관계 유형, 템플릿·필드, 데이터 모델과 검토 자료를 관리한다.

## 현재 상태

- 카테고리 이관 기준 확정
- 범용 관계 유형 2.1~2.5 총 279개 관계 확정
- 279개 관계에 대상 수·역할·허용 템플릿 1차 전면 개편 완료
- 관계 대상 수는 최소 2개, 최대 4개
- 관계명은 템플릿 변수로 사용
- 사용자가 관계 등록 시 허용 템플릿을 선택
- 다음 작업은 2.1부터 관계별 심층 검토

4. 문서 말미 역할·템플릿 총집계
