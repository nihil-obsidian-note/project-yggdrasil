# 범용 관계 유형 현행 기준 통합 갱신본 v1.0

중앙 설정 정비 최신 기준이다. 기존 확정본을 삭제하거나 일괄 수정하지 않고 역사 자료로 보존하며, 충돌하는 판정은 이 문서를 우선한다.

## 1. 문서 지위와 적용 원칙

- 전역 ID는 재번호화하지 않고 1~936을 유지한다.
- 관계 슬롯 총계는 2,813개를 유지한다.
- 범용 관계 유형 데이터는 유지하고 아래 표시명 및 문서 상태 오버라이드를 DB 설계·이관 입력에 적용한다.

## 2. 전체 감사 확정값

- COMMON 관계: 936개
- 역할 슬롯: 2,813개
- 전역 ID: 1~936
- 누락 ID: 0
- 중복 ID: 0
- 2.1~2.10: 752개/2,139슬롯
- 2.11: 34개/125슬롯
- 2.12: 55개/215슬롯
- 2.13: 45개/155슬롯
- 2.14: 41개/152슬롯
- 2.15: 9개/27슬롯
- 룩스테라 용종 SERIES: 808개/1,476슬롯
- 엘드로스 클래스 COMMON 확장: 146개/210슬롯
- 엘드로스 클래스 SERIES: 7개/25슬롯

검증 결과 대상 수와 역할 슬롯 불일치, COMMON 내부 용종·클래스 전용 범주 혼입, 매핑 관계명 누락, 미정의 템플릿 사용은 모두 0건이다.

## 4. 역방향 표시명 충돌 해소

역방향만 충돌하는 항목은 원본 의미와 역할 범위를 보존하고 ID 또는 범주 한정 표시명을 사용한다. DB 내부 키는 전역 ID를 유지하고 UI·문서 출력에만 적용한다.

- ID 80 `본체임(관계 80)`, ID 81 `본체임(관계 81)`
- ID 85 `원형임(관계 85)`, ID 86 `원형임(관계 86)`
- ID 228 `체결 문서임(조약)`, ID 230 `체결 문서임(협정)`
- ID 562 `저항 대상임(관계 562)`, ID 883 `저항 대상임(관계 883)`

## 5. 운영 문서 정합성 오버라이드

- 검토·이관 추적 문서의 `이관 대기`, `위치 미확정`, `보류`, `다음 검토 2.13` 표기는 역사 상태다.
- 현행 상태는 2.1~2.15 검토 완료 및 전체 감사 완료다.
- 인계서의 2.13·2.14 예정 작업은 역사 계획이다.
- 엘드로스 클래스 전용 관계 추가 확정본의 `범용 786개`는 당시 기준값이며 현행 COMMON은 936개다.
- 클래스 SERIES 7개/25슬롯은 COMMON에서 계속 분리한다.

## 6. 이관 및 표시 규칙

1. DB 기본키와 관계 참조는 전역 ID를 사용한다.
2. 원본 관계명은 감사 추적용으로 보존한다.
3. 화면·검색·신규 산출물에는 이 문서의 표시명 오버라이드를 적용한다.
4. 기존 문서의 수량·상태·다음 단계가 이 문서와 충돌하면 이 문서를 우선한다.
5. 새 충돌이 발견되면 ID를 삭제하거나 번호를 당기지 않고 후속 통합 갱신본에서 표시명을 판정한다.

## 7. 종료 판정

전체 감사에서 발견된 정방향 충돌 20쌍과 역방향 충돌 4쌍은 이 문서의 표시명 규칙으로 해소한다. 전역 ID, 역할 슬롯, COMMON/SERIES 분리는 변경하지 않는다.

이 문서를 중앙 설정 정비 폴더의 현행 기준으로 사용한다. 다음 작업은 범용 관계 유형 v1 동결 후 DB 스키마 설계다.
