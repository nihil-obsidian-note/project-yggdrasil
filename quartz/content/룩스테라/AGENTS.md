# 룩스테라 문서 작성 지침

이 폴더와 하위 폴더에서는 저장소 루트 `AGENTS.md`의 공통 운영 규칙을 따른다. 아래 내용은 룩스테라 문서 작성에 추가로 적용하는 기준이다.

## 설정 문서 작성·수정 사전 읽기

`설정` 문서를 새로 작성하거나 수정하기 전에는 반드시 저장소 루트의 [문서 작성 및 수정 지침](../문서 작성 및 수정 지침.md)을 먼저 읽고 따른다. 해당 문서는 본문 형식·문단·표현·사후 점검의 기본 규칙이며, 이 문서는 룩스테라 고유의 메타데이터와 분류 기준을 보완한다.

## 폴더 구조

- `비밀 설정`: 아직 공개 전인 설정
- `설정`: 공개된 설정
- `신격`: 공개된 신격 정보
- `이미지`: 이미지 자료
- `템플릿`: 설정 양식
- `설정 정비`: 신규 적용 사항과 변경 예정 사항
- `스토리 설계`: 이야기 전개와 사건 설계
- `세력 관계`: 세력, 인물, 단체 사이의 관계

템플릿 파일명은 `설정_기본 템플릿`, `설정_국가 템플릿`, `신격_기본 템플릿`처럼 분류와 대상을 드러내는 형식을 사용한다.

## 공통 메타데이터

새 문서는 YAML 프론트매터를 기본으로 사용한다.

- `uuid`: 제목·파일명·링크가 바뀌어도 유지하는 고유 식별자
- `title`: 공통 제목 키. `이름`을 사용하지 않는다.
- `docType`: 문서군 판별값
- `thumbnail`: 값이 없으면 반드시 `''`
- `status`: 문서 진행 상태
- `created_at`: 자동 생성 항목
- `updated_at`: 자동 갱신 항목

기본 `docType`은 `setting`, `deity`, `secret_setting`, `relation`, `story_design`, `maintenance`, `template`을 사용한다.

## 템플릿 문서

템플릿은 신규 문서 작성의 기준 원본이다. YAML 프론트매터에 `title`, `uuid`, `docType: template`, `thumbnail: ''`, `status`, `created_at`, `updated_at`을 포함한다.

설정 계열 템플릿은 필요에 따라 `type`, `subtype`, `region`을 함께 둔다. 빈 값은 `-`가 아니라 반드시 `''`로 기록한다.

## 비밀 설정 문서

`title`, `secret_rank`, `secret_type`, `status`, `created_at`, `updated_at`을 사용한다.

- `secret_rank`: `하급`, `중급`, `상급`, `최상급`, `태고`
- `secret_type`: `인물`, `물건`, `장소`, `개념`, `사건`
- `status`: `시작 전`, `진행 중`, `완료`

## 설정 문서

`title`, `uuid`, `docType: setting`, `thumbnail: ''`, `status`, `type`, `subtype`, `region`, `created_at`, `updated_at`을 사용한다.

- `status`: `시작 전`, `임시작성`, `진행 중`, `완료`
- `type`: `종족`, `사건`, `인물`, `아이템`, `지역`, `대륙`, `국가`, `도시국가`, `단체`, `주요 개념`, `개념`, `신격`, `도시`, `지형`, `부족국가`
- `subtype`: 필요 시 `항구`, `주요`, `일반`, `연맹`, `대륙`, `지침`
- `region`: 필요 시 `에리디안`, `발가르`, `청연`, `네베아`, `실란도르`, `칼디라`, `녹턴`, `카르코사`, `범대륙`, `진홍의 해협`, `심연의 의회`

## 설정 정비와 스토리 설계

- `설정 정비`: `title`, `progress`, `written_on`, `updated_at`을 사용한다. `progress`는 `준비중`, `작성중`, `작성완료` 중 하나다.
- `스토리 설계`: `title`, `type`, `progress`, `written_on`, `updated_at`을 사용한다. `type`은 `스토리` 또는 `구상`, `progress`는 `진행중`, `진행완료`, `설계중`, `준비중`, `작성완료` 중 하나다.

## 신격 문서

`title`, `uuid`, `docType: deity`, `thumbnail: ''`, `pantheon`, `cheongyeon_pantheon`, `status`, `rank`, `alignment`, `domain`, `portfolio`, `created_at`, `updated_at`을 사용한다. 본문은 `# 개요` 이하 내용을 유지한다.

- `status`: `시작 전`, `진행 중`, `완료`
- `rank`: 문맥에 맞게 `반신격`, `소신격`, `중신격`, `대신격`, `주신격`, `초신격` 등을 사용한다.
- `alignment`: 문맥에 맞게 `선신`, `회색신`, `악신` 등을 사용한다.
- `domain`, `portfolio`: 문자열 배열로 기록한다.

## 본문 섹션 골격

문서의 첫 `##` 섹션은 `개요`로 둔다. 이후 실제 내용 섹션은 선택이며, 모든 문서에 `## 항목`을 둔다. `항목`의 본문은 공백을 제외하고 정확히 `내용`으로 고정한다. 실제 요약이 있을 때만 `## 요약`을 `항목` 아래에 두므로, `항목`은 항상 마지막 섹션이거나 `요약` 바로 앞의 마지막에서 두 번째 섹션이다.

## 세력 관계와 링크

세력 관계 문서는 `title`, `relation`, `a_setting`, `a_god`, `b_setting`, `b_god`, `issue`, `session_signs`, `visibility`을 사용한다.

- `relation`: `우호`, `견제`, `대립`, `전쟁`
- `visibility`: `공개`, `부분 공개`, `비공개`
- 연결 항목은 노션 URL이 아닌 옵시디언 위키 링크 `[[문서명]]`으로 기록한다.

파일명 끝의 노션 32자리 아이디는 유지하지 않는다. 내부 링크도 아이디 없는 최종 문서명을 사용하며, 원본 노션 URL은 허용하지 않는다. 매핑이 애매하면 수동 검토 목록으로 분리한다.

`quartz/content`는 원본 문서의 심볼릭 링크 성격이므로 메타데이터 정비 대상은 원본 문서다.
