**Interfaces:**

- Produces: `### 표층 생태권` 아래 표층 지형을 둔 재배치된 `## 핵심 지형 요소`

- [x] **Step 1: 수직 구조 소개 제목을 명확화한다**

`### 두 층으로 이어진 대륙`을 `### 표층과 하층을 잇는 순환`으로 바꾸고, 본문 첫 문장의 표층과 죽은숨 아래의 두 대륙 규모 생태권 관계는 유지한다.

- [x] **Step 2: 핵심 지형 요소의 순서를 바꾼다**

기존 `### 용맥의 심장` 블록을 표층·협곡·하층 블록 뒤로 이동한다. 기존 `### 거목림`부터 `### 창해 해안`까지의 표층 지형에는 새 상위 제목 `### 표층 생태권`을 둔다. 기존 바다피는 협곡과 죽은숨 아래 블록은 내용 변경 없이 표층 생태권 뒤에 둔다.

- [x] **Step 3: 순환을 설명하는 문장에 공간적 순서를 명시한다**

`### 표층과 하층을 잇는 순환`의 첫 두 문단에서 표층, 바다피는 협곡, 죽은숨 아래의 관계가 각각 대륙 규모 생태권·특정 대단층의 경계 생태권·대륙 규모 지하 생태권으로 읽히는지 확인하고, 필요한 최소 연결 문장만 추가한다.

- [x] **Step 4: 변경 내용을 확인한다**
