# 설정 문서 타입별 폴더 이관 설계

## 목표

룩스테라와 엘드로스의 평면 `설정` 문서들을 YAML 프론트매터의 `type`으로 분류한다. 룩스테라의 `region: 청연` 문서는 청연을 우선 경계로 삼아 별도 폴더에서 다시 `type`별로 분류한다. 이후 TRPG 데이터 작업 폴더의 마스터 프롬프트가 새 경로를 기준으로 설정 자료를 찾도록 갱신한다.

## 범위와 불변 조건

- 대상은 `프로젝트 위그드라실/룩스테라/설정`과 `프로젝트 위그드라실/엘드로스/설정`의 Markdown 설정 문서다.
- 문서 본문, 파일명, YAML 값, UUID, 공개 수준은 변경하지 않는다.
- 기존 사용자 변경사항이 있는 문서도 현재 내용 그대로 이동한다.
- `region: 청연`인 룩스테라 문서는 파일명 접두가 아니라 프론트매터 값을 기준으로 판정한다.
- `type`이 없는 문서는 이동하지 않고 검증 실패로 보고한다. 현재 사전 점검에서는 두 설정 폴더의 대상 문서가 모두 `type`으로 분류된다.

룩스테라의 청연 외 문서는 `설정/<type>/`에 둔다. 엘드로스 문서는 `설정/<type>/`에 둔다. `type` 이름과 폴더명은 동일하게 유지한다.

## 경로 갱신

이동 후에는 다음 표면을 조사하고 실제 경로를 전제로 하는 문구·예시·탐색 규칙을 갱신한다.

- `G:\내 드라이브\TRPG 데이터\AGENTS.md`
- `G:\내 드라이브\TRPG 데이터\1. 프롬프트\AGENTS.md`
- `G:\내 드라이브\TRPG 데이터\1. 프롬프트\00. TRPG 세션 매니저 프로젝트 기본 지침.md`
- `G:\내 드라이브\TRPG 데이터\1. 프롬프트\0. TRPG 데이터 프롬프트 통합 마스터 프롬프트.md`
- `G:\내 드라이브\TRPG 데이터\1. 프롬프트\8. 설정 관련 요청 프롬프트` 아래의 마스터·지침 문서
- 그 밖에 옛 평면 경로를 명시적으로 참조하는 로컬 Markdown 파일

내부 위키 링크는 문서명이 유지되므로 먼저 변경하지 않는다. 같은 제목 문서가 새 트리에서 충돌하거나, Markdown 상대 링크 또는 명시 경로가 발견될 때만 해당 참조를 새 경로로 수정한다.

## 검증 기준

1. 각 이동 전 문서가 정확히 한 개의 이동 후 문서로 대응한다.
2. 이동 후 두 시리즈 설정 문서 수와 `type`별 수가 이동 전과 같고, 룩스테라 청연 문서 수와 `type`별 수가 이동 전과 같다.
3. 대상 문서의 내용 해시가 이동 전후 동일하다.
4. 기존 평면 `설정/*.md` 문서가 남지 않는다.
5. 모든 명시 경로 참조와 상대 링크가 존재하는 대상 파일을 가리킨다.
6. 관련 TRPG 데이터 마스터 프롬프트가 새 폴더 체계를 설명하며, Google Drive 직접 접근 지시는 Codex용 로컬 Markdown 규칙과 충돌하지 않는다.
7. `git diff --check`와 Markdown 경로 검사로 이관 결과를 확인한다.
