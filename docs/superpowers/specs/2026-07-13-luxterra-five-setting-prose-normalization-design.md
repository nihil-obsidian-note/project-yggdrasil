# 룩스테라 신규 설정 문서 산문 정비 설계

## 목표

`용종`, `용성`, `아라코크라`, `수인종`, `라크샤라 대륙`의 원본 설정 문서를 문단 중심의 산문 형식으로 정비한다.

## 범위

- YAML 프론트매터와 기존 `##`·`###` 제목은 유지한다.
- 표는 유지한다.
- 문단 내부의 문장 단위 줄바꿈은 공백으로 통합한다.
- 한 문장만으로 독립된 문단은 인접 문단과 통합하거나 설명을 보강한다.
- 마크다운 목록은 자연스러운 서술 문단으로 전환한다.
- 모든 `##` 섹션은 본문 기준 두 문단 이상, 400자 이상이 되도록 보강한다.
- 설정의 사실관계, 고유명사, 옵시디언 링크는 보존한다.
- `quartz/content` 연결본은 직접 수정하지 않는다.

## 설계

각 문서는 기존 섹션 순서를 유지한다. 짧은 도입문은 뒤따르는 설명 문단의 첫 문장으로 합치고, 목록은 항목의 관계가 드러나는 한두 개의 산문 문단으로 재구성한다. 분량이 부족한 섹션은 기존 주제의 원인·영향·현장 활용을 보강해 최소 기준을 충족한다.

## 검증 기준

- 일반 산문 문단에서 문장마다 강제 줄바꿈이 없다.
- 한 문장 독립 문단과 마크다운 목록이 없다.
- 표는 유지한다.
- 각 `##` 섹션은 두 개 이상의 일반 산문 문단과 400자 이상의 본문을 가진다.
