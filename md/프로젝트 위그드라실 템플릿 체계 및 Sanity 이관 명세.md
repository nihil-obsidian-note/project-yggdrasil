# 프로젝트 위그드라실 템플릿 체계 및 Sanity 이관 명세

> 상태: 템플릿 최종 형태를 정리한 단계. 기존 정본 문서와 템플릿 파일에는 아직 적용하지 않았다.
>
> 분류 기준: 카테고리·서브카테고리와 이관 매핑은 [카테고리 및 서브카테고리 이관 정리](프로젝트 위그드라실 카테고리 및 서브카테고리 이관 정리.md)를 정본으로 사용한다.

## 1. 공통 원칙

1. 각 템플릿에 적힌 모든 `##` 섹션은 항상 존재한다.
2. 내용이 없는 섹션은 삭제하거나 숨기지 않고 `-`로 둔다.
3. `항목`은 Markdown 이관용 잔여 섹션이므로 Sanity 대상 템플릿에는 포함하지 않는다.
4. `요약`은 모든 템플릿의 마지막 고정 섹션이다.
5. `###`는 실제로 독립 조회 가치가 있는 고유명사·제도·지역·사건에만 추가한다.

Sanity는 일반 문서의 `_id`를 새로 생성한다. 기존 `uuid`는 `legacyUuid`로 보존하고, `thumbnail`은 이미지 asset 참조로 이관하며, 문서 사이 연결은 reference로 이관한다.

## 2. 최종 템플릿

대상: 전용 템플릿이 없는 개념·규칙·현상.

```md
## 개요
## 정의와 범위
## 기원과 형성
## 작동 방식
## 영향과 활용
## 한계와 예외
## 관련 대상과 관계
## 현재 동향
## 요약
```

## 3. 현행 템플릿의 대응

| 현행 템플릿 | 최종 처리 |
| --- | --- |
| 룩스테라 `설정_도시국가 템플릿`, `설정_항구 템플릿` | `설정_도시 템플릿`으로 통합 후 폐기 |
| 엘드로스 `설정_도시 템플릿` | `설정_도시 템플릿`으로 통일 |
| 엘드로스 `설정_길드 템플릿`, `설정_클랜 템플릿` | `설정_단체 템플릿`으로 통합 후 폐기 |
| 엘드로스 `설정_몬스터 템플릿` | `설정_종족 템플릿`으로 통합 후 폐기 |
| 엘드로스 `설정_클래스 템플릿` | 엘드로스 전용으로 유지 |
| 양 시리즈의 동명 템플릿 | 이 문서의 동명 최종 템플릿으로 통일 |

## 4. 적용 보류와 후속 순서

1. 카테고리·서브카테고리 이관표를 확정한다.
2. 이 문서의 섹션 구조로 룩스테라 템플릿을 개정한다.
3. 엘드로스 템플릿을 대응표에 따라 통합한다.
4. 실제 문서의 분류·본문·저장 경로·링크를 대조한 뒤 이관한다.
5. Sanity 스키마와 Markdown 변환을 검증한다.
